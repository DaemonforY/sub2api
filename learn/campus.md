# 给大学生的 AI 实战课

课程设计要用大模型、简历上缺一个能拿得出手的 AI 项目、实习面试被问到 RAG 和 Agent 答不上来——这几件事，这里的四条路线正好对应。每节课的代码都能在页面里直接运行，不用先配环境、不用先充值。

## 按你的需要选路线

| 你的情况 | 推荐路线 | 学完能拿出来的东西 |
|---|---|---|
| 课程设计 / 毕业设计要接大模型 | [A · AI 应用开发入门](/a/) | 一个带流式输出、多轮对话的网页聊天机器人，或基于你自己资料的问答系统 |
| 想要一个能放进简历的 AI 作品 | [C · AI 编程助手上手](/c/) | 用编程助手做出来并发布上线的网站 |
| 设计、新媒体、做社团海报和视频 | [B · AI 绘画与视频创作](/b/) | 画布社区里的个人作品集 |
| 准备 AI 应用开发岗的实习 / 校招 | [D · AI 面试训练](/d/) | 四组模拟面试的成绩和点评，40 道题的答题思路 |
| 想做大数据开发 / 准备大数据岗面试 | [大数据：Spark、Flink、Paimon](/bigdata/) | 能讲到源码层面的调度、Shuffle、Checkpoint 和湖仓原理 |

建议的顺序：先学 A1–A4 打基础（一个周末就够），再按目标选 B、C 或 D。

## 一个学期可以这样安排

1. **第 1–2 周**：A 路线前四课，调通 API、学会流式输出、结构化输出和 Function Calling。
2. **第 3–4 周**：A5–A8，做出自己的问答机器人，上传到 GitHub。
3. **第 5–6 周**：C 路线，用编程助手给项目做一个介绍网站并发布。
4. **考试周之后**：D 路线刷题库、开模拟面试，每组都过 60 分。

每学完一条路线领一张证书，证书页可以直接贴在简历和作品集里。

## 常见问题

**完全免费吗？**
课程正文、测验、证书都免费。页面里的运行、AI 助教和模拟面试用你自己的 HiveGPT Key，和自己写代码调接口一样，按实际用量从余额扣费。

**没有编程基础能学吗？**
B 路线完全不需要编程；C 路线由编程助手写代码，你负责描述需求和检查结果；A 路线需要会一点 Python 或 JavaScript。

**证书有用吗？**
证书证明你完成了课程、测验和结业项目，有公开的验证页。它不是学历或职业资格证书，真正打动面试官的是证书上附的项目，所以结业项目要认真做。

**学校邮箱不是 edu.cn 结尾怎么办？**
目前只支持页面上列出的邮箱后缀。可以联系客服说明学校，我们会评估是否加入。
