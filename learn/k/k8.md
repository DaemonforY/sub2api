今天的游戏画面已经能做到以假乱真，但很多新游戏偏偏要做成**像素风**、**低多边形**。这节课用同一个场景，带你走一遍游戏美术的四十年，看懂「老派」为什么反而很酷。

## 8-bit：在方格纸上画画

1980 年代的家用游戏机（比如大家说的「红白机」）画面只有 **256×240 个点**，同一屏能显示的颜色也只有二十几种。一个角色往往只有 **16×16 个格子**，每个小角色只能用三种颜色。

所以那时的美术师就像在**方格纸**上画画：每一格都要算计，两个像素就是一只眼睛，一种颜色要同时当头发和阴影。限制越大，越考验设计：这也是为什么那个年代的角色**剪影都特别好认**。

## 16-bit：像素变成了艺术

1990 年代的 16-bit 游戏机能显示的颜色多了很多，像素画家开始用点阵画**光影、渐变和表情**，日式角色扮演游戏的黄金时代就在这时。

他们发明了很多技巧，比如**抖动**（dithering）：颜色不够时，用两种颜色的点像棋盘格一样交错排列，远看就「混」出了一种中间色或渐变。

## 初代 3D：多边形的棱角

1990 年代末，游戏进入 3D。但当时的机器每秒能画的**多边形**（拼出模型的小三角形、四边形）很少，**贴图**（贴在模型表面的图片）也很小。于是角色棱角分明，手像一块块积木，墙面的贴图又模糊又有锯齿。

当年大家嫌它粗糙，今天它却成了一种复古风格，很多独立恐怖游戏专门模仿这种「老 3D」的味道，因为那种模糊和不真实感特别**诡异**。

## 卡通渲染和低多边形：不追求真实

3D 越做越真实以后，有人反过来想：**为什么一定要像照片？**

- **卡通渲染**（三渲二）：用 3D 模型，但按动画的方式上色：硬边阴影、黑色描边。2002 年的《塞尔达传说 风之杖》就是早期的代表，今天很多二次元游戏都用它（[K2](/k/k2) 和 [I8](/i/i8) 讲过）。
- **极简低多边形**：故意只用很少的三角形，每个面一种颜色，干净得像折纸。很多独立游戏用它，因为好看、清爽，小团队也做得出来。

## HD-2D：老像素 + 新光影

2018 年的《八方旅人》让一种新风格火了起来：角色还是**像素画**，但场景放在 **3D 空间**里，有真实的光照、景深模糊和光晕，像在看一个精致的立体模型。它被叫作 **HD-2D**。

这就是游戏美术最有意思的地方：**当年的限制，变成了今天的选择**。像素、低多边形不再是「做不到更好」，而是「我就要这种感觉」：怀旧、简洁、有想象空间。

## 小词典

| 词 | 意思 |
|---|---|
| **像素 / 点阵** | 用一个个小方块画画 |
| **精灵图**（sprite） | 游戏里一个角色或物体的像素图，常常一张图里排着它的所有动作 |
| **调色板** | 一张图或一个角色能用的那几种颜色 |
| **抖动**（dithering） | 用两种颜色的点交错，假装出中间色 |
| **多边形** | 拼出 3D 模型的小三角形、四边形，越多越精细 |
| **贴图** | 贴在 3D 模型表面的图片，决定它的颜色和质感 |
| **卡通渲染 / 三渲二** | 3D 模型按动画的方式上色 |
| **HD-2D** | 像素角色放进有现代光影的 3D 场景 |

## 这节课记住三句话

- 游戏美术的几个时代：**8-bit → 16-bit → 初代 3D → 卡通渲染 / 低多边形 → HD-2D**。
- 像素和低多边形，最早是**机器的限制**，今天是**一种审美**：怀旧、简洁、有想象空间。
- 看一个游戏的美术，就问三件事：**是哪一派、有什么看得见的特点、为什么适合它**。
