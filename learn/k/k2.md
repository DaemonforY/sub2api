## 老祖宗：浮世绘

浮世绘是日本江户时代（大约 17 到 19 世纪）的**流行版画**。它不是挂在宫殿里的名画，而是印很多份、便宜卖给普通人的：名胜风景、人气演员、美人、故事，有点像今天的海报和周边。

为什么浮世绘的线那么清楚、颜色那么平？因为它是**木版印刷**：先刻一块印黑线的版，再给每种颜色各刻一块版，一块一块套印上去。一块版只能印一种平平的颜色，所以有了「线 + 平涂」。

两百年后，动画和漫画也走上了「清楚的线 + 平涂」这条路（下面会讲为什么），所以你会觉得浮世绘「很像动漫」。

## 漫画：从「漫画之神」开始

现代日本漫画绕不开**手冢治虫**（1928–1989），大家叫他「漫画之神」，代表作是《铁臂阿童木》。他做了两件影响到今天的事：

- **像拍电影一样画漫画**：特写、远景、俯视、仰视，一页里的格子像电影的镜头；
- **大大的眼睛**：他受到早期美国动画的影响，把角色的眼睛画得很大、很有表情，后来成了日式漫画的标志。

漫画里那些「黑白也能看出颜色和速度」的工具：

| 工具 | 是什么 | 写进提示词 |
|---|---|---|
| **网点** | 一层层小圆点，用来表示灰色和阴影 | 用网点纸表现灰色和阴影 |
| **速度线** | 一束平行或放射的线，表示快速运动 | 速度线、集中线 |
| **效果线** | 角色身后放射的线，表示震惊、紧张 | 背景是放射状的集中线 |
| **分镜** | 一页漫画里一格一格怎么排 | 一页四格漫画、横版分镜 |

## 动画：为什么人物简单、背景精细？

老动画是一张张画出来的。人物画在一种透明的胶片上，这种胶片叫**赛璐璐**（celluloid）；背景单独画在纸上。拍的时候把透明的人物片叠在背景上，一格一格拍下来。

| 步骤 | 做什么 |
|---|---|
| 分镜 | 先画一本「漫画版剧本」，决定每个镜头拍什么 |
| 原画 | 画出动作里最关键的几张（起点、终点、最用力的那一下） |
| 中间画 | 补上关键张之间的过渡，让动作连起来 |
| 上色 | 给每一张人物上颜色 |
| 背景美术 | 美术师画出每个场景的背景，一张就是一幅风景画 |
| 摄影 | 把人物和背景叠在一起，加上光效、镜头晃动 |

这就是 [I8](/i/i8) 里「手绘动画电影背景」那种样子的原因：

- **人物要一张张画、一张张上色**，一秒钟就要好几张，所以只能用干净的线、平涂的颜色、一层阴影。这就是**赛璐璐风格**。
- **背景一个镜头只要画一张**，美术师可以慢慢画成精细的水彩、水粉风景画。

所以动画里常常是「简单的人站在一幅很美的画里」。今天动画早就是电脑上色了，真正的透明胶片已经不用了，但这种好看的画法留了下来，名字也还叫「赛璐璐」。

::: tip 冷知识
电视动画一般是一秒 24 格画面，但为了省力，常常一张画拍 3 格，叫「一拍三」，这样一秒只要画 8 张。所以动画里人物动作有一种「一顿一顿」的节奏感，那也是动画味的一部分。
:::

## 几个值得认识的名字

学习的时候知道这些名字很有用；**用 AI 画图时，把他们的特点写成特征，而不是直接写名字**（[I8](/i/i8) 讲过为什么）。

| 名字 | 代表作 | 特点 | 想要类似的感觉，可以写 |
|---|---|---|---|
| 宫崎骏 / 吉卜力工作室 | 《龙猫》《千与千寻》（拿过奥斯卡最佳动画长片） | 手绘、自然、飞行和风、认真吃饭的日常 | 水彩水粉手绘背景、积雨云、被风吹动的草、生活痕迹 |

| 京都动画 | 《紫罗兰永恒花园》 | 细腻的日常、柔和的光、精致的小动作 | 柔和的光、浅景深、细腻的表情和手部动作 |
| ufotable | 《鬼灭之刃》 | 手绘人物 + 华丽的特效和 3D 镜头 | 浓烈的特效光、水和火焰的流线、动态镜头 |

新海诚早年几乎**一个人**在电脑上做出了短片《星之声》，后来才有了大电影。他的很多场景照着现实中的街道和车站来画，粉丝会专门去这些地方拍照打卡，这叫**圣地巡礼**。

游戏里还常听到这些说法：

| 说法 | 是什么 |
|---|---|
| **立绘** | 角色站着的全身图，视觉小说和手游里对话时出现的那张 |
| **卡面** | 抽卡游戏里一张卡的完整插画，常常是带场景的厚涂 |
| **KV** | Key Visual，主视觉，一个游戏或动画的宣传主图 |
| **概念图** | 开发前画的设定图，用来定下世界的样子和气氛 |
| **三渲二** | 卡通渲染，3D 模型渲染成 2D 动画的样子 |
| **等距 / 2.5D** | 斜着 45 度往下看的小世界，模拟经营游戏常见 |

## 动手写：说说它好看在哪

选一张你喜欢的动漫截图、漫画页或游戏画面，**凭记忆描述也可以**。用这节课的词说说它好看在哪：

- 线条和颜色是什么样的？是赛璐璐、厚涂、像素，还是三渲二？
- 光从哪里来？是什么时间、什么天气？
- 构图怎么安排？人物大还是小？
- 它让你想到什么、有什么感觉？

至少写三句话，越具体越好。「好看」「绝美」这种词不算数，要说**看得见的东西**。

## 这节课记住三句话

- 动漫的「清楚的线 + 平涂」可以一路追到浮世绘：木版印刷，一块版一种颜色。
- 动画里人物简单、背景精细，是因为人物要一张张画、背景一个镜头只画一张，这就是「赛璐璐」的由来。
- 游戏美术的常用词：像素、立绘、卡面、KV、概念图、三渲二、等距。知道这些词，刷图和写提示词都更准。
