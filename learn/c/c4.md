网页在自己电脑上能打开，别人还看不到。发布就是把这些文件放到一台服务器上，给它一个网址。HiveGPT 的订阅用户可以直接在「我的网站」里发布。

## 准备文件

「我的网站」接受两种上传：

- **单个网页文件**：一个 `.html` 或 `.htm` 文件，发布后保存为 `index.html`。上一课做的单文件网页直接传这个就行。
- **一个 zip 包**：网站有图片、多个页面时用。`index.html` 要放在 zip 的根目录，或者放在 zip 里唯一的一个文件夹中。

上传前在浏览器里再打开一遍，确认页面正常。如果网页引用了图片，检查图片路径是相对路径（如 `images/logo.png`），而不是你电脑上的路径（如 `C:\Users\...`）。

::: warning 静态网站没有后端
「我的网站」只托管静态文件，没有后端程序。访问者能看到网页里的全部代码，所以**任何 Key 都不能写进网页的 JavaScript 里**。上传前搜一下文件里有没有 `sk-`。
:::

## 发布

1. 登录 [HiveGPT](https://hivegpt.cn/)，打开左侧菜单的「我的网站」。
2. 填写表单：
   - 「网址（可选）」：留空会自动生成，也可以自己起，例如 `my-shop`。要求 3–30 个字符，只能用小写字母、数字和连字符，并以字母开头。
   - 「网站名称（只有你能看到）」：方便自己区分，比如「咖啡店主页」。
   - 「网页文件（.html 或 .zip）」：选择上一步准备好的文件。
3. 点「发布」。

发布后网址是：

```text
https://<网址>.s.xinduanju.top
```

上传的内容会经过自动检查，被标记的版本要等人工审核后才能访问。

## 规则和管理

| 项目 | 默认规则 |
|---|---|
| 谁能用 | 订阅用户（未订阅会提示「网站发布只对订阅用户开放」） |
| 网站数量 | 每人最多 3 个，含 1 个；多出的每个 ¥5 / 30 天，从余额扣（以页面显示为准） |
| 大小 | 每个网站 20MB、500 个文件以内 |
| 版本 | 保留最近 3 个版本，可以回滚 |
| 访问密码 | 可选，设置后访问者要输入密码才能看 |

改了网页之后重新上传，就是一个新版本；新版本有问题，回滚到上一个版本即可。

## 没有订阅也能发布

也可以发布到其他平台，比如 GitHub Pages、Gitee Pages 等。把项目推到一个公开仓库，按平台说明开启网页托管，就能得到一个 https 网址。同样注意：仓库里不能有 Key。

## 提交结业项目

回到这条路线的路线页，在结业区域提交你的网站网址：「我的网站」里发布的地址，或者 GitHub / Gitee 等平台上的公开链接。

## 小结

- 上传单个 .html 文件，或根目录（或唯一文件夹）里有 index.html 的 zip 包。
- 「我的网站」发布后网址是 `https://<网址>.s.xinduanju.top`，保留 3 个版本，可设访问密码。
- 静态网站没有后端，网页里永远不要放 Key；没有订阅可以用 GitHub Pages、Gitee Pages 等发布。

学完这条路线后，到路线页领取结业证书。
