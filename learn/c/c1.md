编程助手和聊天网页最大的区别是：它在**你的电脑上、你的项目文件夹里**工作。它能看到文件、新建和修改文件、运行命令，所以能真正把代码写出来。这条路线用的是 Codex CLI，一个在终端里运行的编程助手；背后的模型通过 HiveGPT 调用 `gpt-5.5`。

## 第一步：安装 Codex CLI

Codex CLI 需要 Node.js 18 或更高版本。先在终端里检查：

```bash
node -v
```

没有输出版本号，或者版本低于 18，先到 Node.js 官网下载安装长期支持版（LTS）。然后安装 Codex CLI：

```bash
npm install -g @openai/codex
```

::: tip 什么是终端
macOS 打开「终端」（Terminal），Windows 打开「PowerShell」或「Windows Terminal」。后面所有命令都在这里输入，回车运行。
:::

## 第二步：创建一个 Key

1. 登录 [HiveGPT](https://hivegpt.cn/)，打开左侧菜单的「API 密钥」，点「创建密钥」。
2. **分组**选 OpenAI 类的分组，比如「GPT-按量」：按实际用量从余额扣费，用多少扣多少。
3. 创建好之后先不用急着复制，下一步的弹窗会帮你把 Key 填进配置里。

## 第三步：用「使用密钥」生成配置

在 Key 列表里找到刚建的 Key，点「使用密钥」，会打开「使用 API 密钥」弹窗：

1. 客户端选「Codex CLI」（也支持 OpenCode 等，这条路线以 Codex CLI 为例）。
2. 系统选「macOS / Linux」或「Windows」。
3. 认证方式保持默认的「兼容模式」。
4. 弹窗会给出两个文件的内容：`~/.codex/config.toml` 和 `~/.codex/auth.json`。按弹窗里的提示创建或修改这两个文件，**把内容放在 config.toml 文件的开头部分**。

生成的 config.toml 大致长这样（仅作示意，**以弹窗里的内容为准**，它会填好当前的接口地址）：

```toml
model_provider = "OpenAI"
model = "gpt-5.5"
review_model = "gpt-5.5"
disable_response_storage = true
model_catalog_json = "~/.codex/codex-models.json"
network_access = "enabled"
windows_wsl_setup_acknowledged = true

[model_providers.OpenAI]
name = "OpenAI"
base_url = "https://hivegpt.cn/v1"
wire_api = "responses"
requires_openai_auth = true
```

auth.json 里只有一项 `OPENAI_API_KEY`，值就是你的 Key。

::: warning Key 等同于密码
- auth.json 放在你的用户目录下，不要复制到项目文件夹里，更不要提交到 GitHub。
- 不要把 Key 贴进聊天记录、截图或给编程助手的任务描述里。
- 泄露了就到「API 密钥」页删除，再建一个新的，并重新生成配置。
:::

## 第四步：启动，完成第一次对话

编程助手会在你启动它的文件夹里工作，所以先建一个专门的项目文件夹：

```bash
mkdir my-site
cd my-site
codex
```

进入会话后，先问一个不改文件的问题，确认接通了：

```text
你好，用两句话介绍一下你能在这个文件夹里帮我做什么。
```

能正常回复，说明 Codex CLI 已经通过 HiveGPT 调用到了模型。会话里输入 `/` 可以看到可用的命令。

几点要知道：

- 它要运行命令或修改文件时，会根据当前的审批模式先征求你的同意。**看清楚它要做什么再同意**，尤其是删除文件、安装软件这类操作。
- 每一次对话都会消耗 token，「GPT-按量」分组按用量从余额扣费。在 HiveGPT 的「使用记录」里能看到明细。
- 遇到 401，通常是 Key 复制错了或已被删除；提示模型不可用，检查 Key 的分组是不是 OpenAI 类分组。

## 小结

- Codex CLI 用 `npm install -g @openai/codex` 安装，需要 Node.js 18+。
- 配置从「使用密钥」弹窗复制，选「Codex CLI」和「兼容模式」，不要手敲。
- 在项目文件夹里运行 `codex`；它改文件、跑命令前会征求同意，看清楚再点。
