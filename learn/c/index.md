# C · AI 编程助手上手

<TrackPage id="c" />

## 这条路线讲什么

编程助手能读你的项目、写代码、运行命令，但它做得好不好，很大程度取决于**你怎么给它布置任务、怎么检查它的结果**。这条路线用一个具体项目串起来：用编程助手做一个小网站，然后发布上线。

1. **安装和接入**：装好 Codex CLI，用 HiveGPT 的 Key 接上 `gpt-5.5`。
2. **写网页**：把模糊的想法写成清晰的任务描述，让它先给计划再动手，检查改动，用 git 保存每一步。
3. **调试和改需求**：报错时给它准确的信息，一次只改一件事，知道什么时候该自己动手。
4. **发布**：在「我的网站」里上传，得到一个可以分享的网址。

每节课都有「动手试试」，用 HiveGPT 的接口直接运行：登录后选一个你自己的 Key，按用量从余额扣费；真正写代码时用的也是这个 Key。

## 结业

满足下面四个条件，可以在本页领取这条路线的结业证书：

- 学完 4 课；
- 测验总正确率 ≥ 80%；
- 完成检查点：在「API 密钥」页创建一个 Key，并用自己的 Key 成功调用一次 API（C1 里有这两个检查点）；
- 提交结业项目：你在「我的网站」里发布的网站，或者放在 GitHub / Gitee 等平台上的公开链接。
