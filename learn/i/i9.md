v1 就是一张「AI 图」：不难看，但没有情绪，也没有故事。每多一句，它就更像**你想要的那张**。

## 六步，从脑洞到壁纸

### 1. 一句话说清点子

公式：**谁 / 什么 + 在哪 + 有什么奇怪的地方**。奇怪的地方是关键：

- 金鱼 + 城市上空 + 像在水里一样游
- 鲸鱼 + 沙滩上空 + 是彩色玻璃做的（[I7 质感](/i/i7)）
- 小镇 + 夜晚 + 每扇窗里都住着一颗星星

想不出来？试试「把东西放错地方」「换成意想不到的材质」「把大小反过来」。

### 2. 定一个情绪

治愈？孤独？热血？怀旧？神秘？**先定情绪**，后面每一步都按它来选。金鱼那张，我们要的是「雨后的、有点魔幻的温柔」。

### 3. 按情绪挑每一句

| 这一句 | 回去复习 | 金鱼的选择 |
|---|---|---|
| **画风** | [I8 画风图鉴](/i/i8) | 日系动画电影风格 |
| **光** | [I3 打光](/i/i3)、[I1 剪影](/i/i1) | 雨后傍晚，夕阳从云缝照来，鳍被照透 |
| **配色** | [I4 配色](/i/i4) | 蓝紫为主，橙红是最亮的点缀 |
| **镜头** | [I6 镜头](/i/i6) | 从街道仰视，长焦 |
| **构图** | [I5 构图](/i/i5)、[I2 近大远小](/i/i2) | 金鱼在中部偏上，行人在下方衬出大小 |
| **质感** | [I7 质感](/i/i7) | 薄纱一样透亮的鳍，积水的街道反光 |

不必每一句都用上，但**画风、光、配色、构图**这四样最好都有。

### 4. 按顺序写成一段

```text
【画风】{画风}。
【镜头】{镜头和它的效果}。
画面内容：{时间和天气}，{点子：谁在哪做什么奇怪的事}，{质感细节}；{参照物或生活痕迹}。
配色：{主色}为主，{点缀色}是全画面最亮的点缀。
构图：{竖版手机壁纸 / 横版电脑壁纸}，{主体在哪}，{留出哪里放时间或图标}。
```

画风和镜头放在**最前面**（[I8](/i/i8) 讲过为什么），画面内容在中间，配色和构图收尾。

### 5. 画 → 看 → 改一处 → 再画

第一张不满意很正常。**别整段推翻**，按这个顺序检查：

1. **眯眼看**（[I1](/i/i1)）：主体还认得出吗？明暗有没有拉开？
2. **颜色乱不乱**：有没有一个说了算的主色？阴影有没有发灰？
3. **视线去哪了**：眼睛是不是先落在主体上？
4. 看 **AI 老师的建议**：它每次只给一条最重要的。

然后**一次只改一两处**，再画。改太多，你就不知道是哪一句起的作用。

我们的 v3 就没有一次成功。AI 老师给了 86 分，「适合当壁纸」只有 63 分：**顶部被鱼鳍和云占满了，时间会压在金鱼上**。建议只有一条：把金鱼缩小下移，顶部四分之一只留干净的天空。我们只改了构图那一句，画出了 v4：

### 6. 做成壁纸

| | 手机壁纸 | 电脑壁纸 |
|---|---|---|
| 比例 | 竖版（这里用 1024×1536） | 横版（1536×1024） |
| 留白 | **上方**留一块干净的天空或墙，放时间 | **左边或中间**留一块干净的地方，放图标 |
| 主体 | 放在中部偏上或中下部，别被时间挡住 | 放在三分线上，别被图标挡住 |
| 细节 | 别太花，不然图标看不清 | 可以更开阔、细节更多 |

## I 路线的全部，浓缩成三句话

- **先有点子和情绪**，再选画风、光、配色、构图、镜头、质感；每一课都是提示词里的一句。
- 画风和镜头写在**最前面**，每一句都写**效果**，不写空话。
- **画 → 眯眼看 → 改一处 → 再画**，好图是改出来的。
