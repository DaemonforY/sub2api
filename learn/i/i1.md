画家判断一张画好不好，有个很土但很灵的办法：**眯起眼睛看**。

眯眼以后，细节和颜色都糊掉了，只剩下大块的**亮和暗**。好看的画，这时候主体依然一眼就认得出；不好看的画，会变成一片灰。

## 先试试：同一个画面，眯眼以后

左边的问题不是画得不好，而是**主体和背景一样亮**。眼睛找不到重点，画面就显得灰、平、没精神。

::: tip 自己检查的办法
画完一张图，把它**缩到很小**（比如手机相册的缩略图），或者真的眯起眼睛看。还认得出主体，就过关了。
:::

## 让主体跳出来的两种办法

### 1. 暗主体，亮背景（逆光剪影）

主体放在**很亮的背景**前面：夕阳、朝阳、亮着的窗、发光的海面。主体自然就成了深色的剪影。适合**怀旧、伤感、壮阔**的画面。

### 2. 亮主体，暗背景（聚光）

把整个画面压暗，**只照亮主体**：一盏灯笼、一束舞台光、从窗户漏进来的一道光。适合**神秘、温暖、孤独**的画面。

两种办法的道理一样：**主体和背景的明暗要拉开**。最怕的是第三种：什么都差不多亮。

让剪影好认的，都是**伸出轮廓之外的东西**：帽子、武器、飘起来的斗篷和围巾、张开的手臂、动物竖起的耳朵。主体的姿势也要**侧一点、张开一点**，两只手贴着身体站直，剪影就成了一根柱子。

## 明暗三块：亮、中、暗

再进一步，可以把整张画想成**三块明暗**：

- **亮**：天空、光源、被照亮的主体；
- **中**：大部分的地面、远景；
- **暗**：剪影、阴影、近处的前景。

每一块都**大而完整**，主体放在对比最强的地方（最亮挨着最暗），画面就有了骨架。细节再多，都是在这副骨架上加的。

## 光那一句怎么写

在 [I3 打光](/i/i3) 学过的光，加上「主体亮还是暗」就够了：

```text
【光】暗主体亮背景：{太阳刚落到山后 / 朝阳从海面升起}，天空很亮，
{主体}是深色的剪影，轮廓清晰：{能认出它的特征，比如帽子、围巾、狗的耳朵}都看得清。

【光】亮主体暗背景：{漆黑的森林 / 深夜的房间}，只有{灯笼 / 台灯 / 一束光}照亮{主体}，
四周沉在深蓝黑色里。
```

## 这节课记住三句话

- 画完先**眯眼看**：去掉细节以后，主体还认得出，明暗就是对的。
- 让主体跳出来：**暗主体配亮背景**，或者**亮主体配暗背景**，最怕什么都一样亮。
- 好剪影靠**伸出轮廓的特征**：帽子、武器、飘起的围巾、张开的手臂。
