动画和电影里那些让人起鸡皮疙瘩的画面，很多时候靠的不是画得多细，而是**镜头选得好**：巨大的月亮压在主角身后，从地面往上仰望的英雄，透过栏杆缝隙偷看的一眼……

AI 画图也一样：同一句画面内容，前面加一句**镜头**，情绪就完全不同。

## 镜头的三个旋钮

### 1. 焦距：广角还是长焦

- **超广角**：把近处放大、远处缩小，透视线一路冲向远方。空间显得**巨大**，适合宏伟的建筑、开阔的风景、冲向镜头的动作。
- **长焦**：把远处的东西「拉近」，前后被压缩到一起。月亮、夕阳、远山会显得**特别大**，适合浪漫和宿命感的画面。动画里「主角站在巨大月亮前」的经典镜头，就是长焦。

### 2. 机位：从哪里看

| 机位 | 效果 | 适合 |
|---|---|---|
| **平视** | 平常、真实 | 日常、对话 |
| **仰视 / 虫视** | 人物高大、有压迫感或力量感 | 英雄登场、巨大的建筑和怪兽 |
| **俯视 / 鸟瞰** | 人物渺小、像在旁观 | 孤独、迷路、展示城市和地图 |
| **荷兰角**（倾斜） | 世界「歪了」，不安、紧张 | 悬疑、恐怖、混乱、醉酒 |

[J7 漫画分镜](/j/j7) 里讲过仰视和俯视，这里再加两个更极端的：贴着地面的**虫视**和正上方的**鸟瞰**。

### 3. 焦点：看清什么、虚化什么

- **浅景深**：只有主体清晰，背景虚化。夜景的灯会变成一个个**圆形光斑**，画面立刻有「心动」的感觉。
- **前景遮挡**：在镜头前放一点模糊的东西（栏杆、树叶、玻璃、门缝），观众就像**躲在后面偷看**，有秘密感和故事感。
- **过肩**：从一个人的肩膀后面拍另一个人，画面里就有了**两个人的关系**，适合对话、告白、对峙。

## 按情绪选镜头

| 想要的情绪 | 试试这个镜头 |
|---|---|
| 宏大、震撼 | 超广角 + 仰视 |
| 浪漫、命中注定 | 长焦（巨大的月亮、夕阳） |
| 孤独、渺小 | 鸟瞰 / 俯视 + 人物很小 |
| 帅气、有力量 | 虫视 / 仰视 |
| 紧张、不安 | 荷兰角 |
| 心动、专注 | 浅景深特写 |
| 秘密、被注视 | 前景遮挡 |
| 两个人的关系 | 过肩 |

## 镜头那一句怎么写

镜头和画风一样，**写在前面**，用「【镜头】」开头（[I8](/i/i8) 讲过为什么要放前面）：

```text
【画风】{画风}。
【镜头】{长焦镜头，远处的月亮被压缩得非常巨大 / 超广角，近大远小非常夸张 /
虫视角，摄像机贴着地面往上拍 / 鸟瞰，摄像机在正上方往下拍 / 荷兰角，画面倾斜 25 度 /
浅景深特写，背景虚化成圆形光斑 / 前景遮挡，透过模糊的栏杆看过去 / 过肩镜头}。
画面内容：{谁、在哪、做什么}。
```

::: tip 把效果写出来
只写「长焦」两个字，模型不一定照做；把**效果**一起写出来更稳：「远处的月亮被压缩得非常巨大，几乎占了半个天空」。
:::

## 这节课记住三句话

- 镜头有三个旋钮：**焦距**（广角 / 长焦）、**机位**（虫视 / 平视 / 鸟瞰 / 荷兰角）、**焦点**（浅景深 / 前景遮挡 / 过肩）。
- **先定情绪，再选镜头**：浪漫用长焦，宏大用广角仰视，孤独用鸟瞰，紧张用荷兰角。
- 镜头写在前面，**连效果一起写**。
