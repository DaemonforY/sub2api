同样的东西，放在画面不同的位置，讲的是不同的故事。**构图就是决定「东西放在哪、多大、画面里还留下什么」**，好的构图让观众的眼睛按你安排的路线走。

## 先看一幅画

## 眼睛先看哪里：视觉重心

观众看一张图，眼睛不是平均扫过去的，而是被**对比**拉过去。下面这些对比越强的地方，越容易成为视觉重心：

- **明暗**：最亮或最暗、和周围反差最大的地方（上一课讲过）。
- **颜色**：一片灰里的一点红，一片冷色里的一点暖色。
- **大小**：画面里最大的形，或者大片里孤零零的一个小点。
- **清晰度**：清楚的东西比模糊的东西更抢眼，所以摄影里用浅景深虚化背景。
- **人和字**：人的脸、眼睛，以及文字，天生就会吸引视线。

一张画最好只有**一个**最强的重心。处处都在抢眼，等于哪里都不重要。

| 构图 | 怎么做 | 给人的感觉 |
|---|---|---|
| 中心 / 对称 | 主体放正中，两边对称 | 稳定、庄重、仪式感；用不好会呆板 |
| 三分法 | 用两横两竖把画面分九格，主体放在线上或交点附近 | 自然、有动感，最通用 |
| 对角线 | 主要的线条或形体斜穿画面 | 运动、紧张、速度感 |
| 引导线 | 道路、河流、栏杆把视线一路引到主体 | 纵深、带着观众「走进去」 |
| 框中框 | 门、窗、树枝、拱桥在画面里再围出一个框 | 聚焦、偷看感、层次 |
| 留白 | 主体很小，大面积空着 | 安静、孤独、辽阔、想象空间 |

还有一条小规则：**人物朝哪边看、往哪边走，前方就多留一点空间**。比如一个人站在画面右边缘、脸朝右看，视线一出画就撞上边框，画面会显得憋闷；把他挪到左侧三分线上，右边留出他望向的空间，就舒展了。

## 东方的构图：留白

中国画很早就把「空」当成画面的一部分。南宋画家马远常把山石树木集中在画面一角，其余大片空着，人称「马一角」。下面这幅《高士观瀑图》就是这样：

留白不是没画完，而是「计白当黑」：空的部分和画出来的部分互相衬托。后面学国风和诗画时还会再用到它，诗句往往就题在这片空白里。

::: info 关于「黄金比例」
很多文章说名画都藏着黄金螺旋。其实大多数是事后把线硬套上去的，美术史上能确认画家刻意使用的例子并不多。实用的结论是：主体不要贴边，也不要总放正中，放在大约三分之一到五分之二的位置往往就舒服。三分线（33%）和黄金分割线（38.2%）离得本来就很近，上面的画都可以两种线切换着看看。
:::

## 在提示词里写构图

模型会尽量照你写的位置来画，但它不会主动替你经营画面。写构图时说清这几件事：

| 想清楚 | 可以这样写 |
|---|---|
| 画幅 | 横版 3:2 / 竖版 2:3 / 方形。先选对画幅，构图才有空间 |
| 主体在哪、多大 | 人物位于画面右侧三分之一处，只占画面的一小部分 |
| 视线怎么走 | 一条小路从画面左下角蜿蜒通向远处的人物 |
| 剩下的地方是什么 | 左上方大片留白，是阴天的天空和薄雾 |
| 从哪里看 | 低角度仰拍 / 俯拍 / 平视 / 透过门洞看出去 |

只写「构图优美」「黄金分割构图」，模型多半还是把主体放在正中间。**把位置、大小和引导线写出来，比写构图术语管用。**

## 小结

- 眼睛跟着对比走：明暗、颜色、大小、清晰度、人和字。一张画最好只有一个最强的重心。
- 六种常用构图：中心对称、三分法、对角线、引导线、框中框、留白，各有各的情绪。
- 人物朝向和运动方向的前方要多留空间。
- 中国画的留白是画面的一部分，马远的「马一角」是经典例子。
- 提示词里写清画幅、主体位置和大小、引导线和空白处是什么，别只写「构图优美」。
