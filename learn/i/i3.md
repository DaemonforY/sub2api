你有没有发现：动漫里一到黄昏，气氛就开始不对劲了，不是要告白就是要告别。游戏里同一张地图，白天轻松愉快，一到夜里就让人紧张。

这背后只有一个秘密：**光**。画面里的东西一点没变，换个光，就是另一个故事。

是不是光一变，你脑子里就自动冒出了不同的剧情？以后想画一种「感觉」，先想**它应该发生在一天里的什么时候**，这比写一堆「唯美」「治愈」管用得多。

## 打光只要想清三件事

不用背术语，每次画图前问自己三个问题：

1. **光从哪来？** 太阳、窗户、路灯、霓虹招牌、手里的手电筒……在人物前面、旁边还是身后？
2. **光是什么颜色？** 暖的（橙、金、黄）让人觉得温暖、怀念；冷的（蓝、紫、青）让人觉得安静、清冷、神秘。
3. **光是硬还是软？** 大太阳下影子边缘锋利，是「硬光」，显得热烈、有力；阴天或者隔着窗帘，影子模模糊糊，是「软光」，显得温柔、安静。

| 光 | 适合画什么 | 提示词可以这样写 |
|---|---|---|
| 正面光 | 日常、头像、可爱的立绘 | 光从正面照来，画面干净明亮 |
| 侧光 | 帅气、坚定、有心事的角色 | 光从画面左侧照来，脸一半在阴影里 |
| 逆光 + 轮廓光 | 告白、告别、回忆、主角登场 | 夕阳在人物身后，头发和肩膀边缘有一圈金色的轮廓光 |
| 丁达尔光柱 | 森林、教堂、遗迹、神明登场 | 阳光从树叶缝隙斜射下来形成光柱，空气里有薄雾和光尘 |
| 霓虹光 | 赛博朋克、夜晚都市、雨夜 | 粉紫色和青蓝色的霓虹灯从两侧照来，湿漉漉的地面反射灯光 |
| 底光 | 恐怖、篝火边讲故事、反派 | 火光 / 手电筒从下往上照，阴影朝上 |

::: tip 光柱为什么画不出来？
很多人写了「丁达尔效应」却只得到一扇很亮的窗户。光柱要两样东西同时在场：**一个漏光的缝隙**（树叶、窗户、云缝）和**空气里能被照亮的东西**（雾、灰尘、水汽）。两样都写上，光柱就出来了。
:::

## 「新海诚式」天空的秘密

很多人喜欢的那种「每一帧都能当壁纸」的天空，其实是有规律的。下面两张图只差在描述天空的那一句：

<CompareGrid
  :cols="2"
  base="日系动画背景风格，傍晚，一座长满青草的小山坡上有一棵孤零零的树。{}"
  items='[{"src":"/art-lab/i3-sky-plain.webp","label":"只写「傍晚的天空」","change":"天空：傍晚的天空"},{"src":"/art-lab/i3-sky-rich.webp","label":"把天空的规律写出来","change":"橙粉到深蓝紫的渐变、低空厚积云镶金边、云的暗部是蓝紫色、空气通透、早出的星星、一点镜头光晕"}]'
/>

拆开来就是这几条，画风景时直接抄：

- **天空分层渐变**：地平线附近暖（橙、粉），头顶冷（蓝、紫），中间别糊成一团灰。
- **云又低又厚**，被夕阳照到的边缘发金光。
- **阴影是蓝紫色的，不是黑色**：暗部受天空影响，所以动漫画面再暗也很通透。
- **空气很干净**：远处的山、城市都看得清楚，再点几颗星星或几只鸟。
- **一点点光晕**：太阳附近加镜头光晕和光斑，电影感一下就出来了。

::: warning 别直接写画师或作品的名字
「XX 风格」「像某某动画」这种写法，模型不一定理解得准，而且涉及在世画师的风格时，平台往往会限制。**把你喜欢的那种风格的特点写出来**，效果更稳，也更像你自己的作品。
:::

## 动漫的影子：不是黑，是彩色的

自己留意一下动漫截图里的阴影：皮肤的暗部偏粉橙，白衬衫的暗部偏淡紫，夜景的暗部是深蓝。动漫常把阴影简化成**边缘清楚的一两层**（这就是「赛璐璐」上色），而且阴影带颜色。

所以想要动漫感，可以在提示词里加一句：「阴影边缘清晰，暗部带一点蓝紫色，不要死黑」。

## 光影小词典

画图时卡住了，就从这里挑：

| 想要的感觉 | 可以写 |
|---|---|
| 青春、夏天 | 正午强烈的阳光、积雨云、短而硬的影子、高饱和的蓝天 |
| 怀念、心动、告别 | 黄昏、魔法时刻、逆光、轮廓光、长长的影子 |
| 安静、治愈 | 阴天的柔光、透过窗帘的光、清晨的薄雾 |
| 神秘、神圣 | 光柱、光尘、只照亮一小块的光、四周暗下去 |
| 孤独、温暖 | 夜晚、一扇亮着的窗户、一盏路灯、雪 |
| 酷、未来感 | 霓虹、雨夜反光、冷暖两种颜色的光从两边打来 |

::: details 彩蛋：300 多年前的画家也这么打光
荷兰画家维米尔特别爱画「窗边的人」：整个房间只有一扇窗户的光，从左边照进来。点「灰度」按钮去掉颜色，你会发现最亮的地方正是头巾和墙角，离窗最近的地方。今天动漫里「窗边的少女」，打光思路和它一模一样。

## 这节课记住三句话

- 想要一种感觉，先想它发生在**什么时候**。
- 打光三问：**从哪来、什么颜色、硬还是软**。
- 名场面的光就那几种：逆光轮廓光、光柱、霓虹、窗边光，抄小词典就行。
