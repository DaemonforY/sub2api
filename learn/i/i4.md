## 通透的三个秘密

### 1. 颜色有主次

一张画里颜色可以很多，但**说了算的只有一两种**。还记得 [J1](/j/j1) 的 60 / 30 / 10 吗？配色也一样：

- **主色**（约六成）：定下整张画的情绪，比如傍晚的蓝紫；
- **辅色**（约三成）：和主色搭配，比如夕阳的橙；
- **点缀色**（约一成）：全画面最亮、最跳的那一点，放在主角身上，比如黄雨衣。

左边那张的问题，就是每种颜色都在抢「主角」。

### 2. 暖光冷影：阴影不要加黑

这是动漫配色最重要的一招。**被阳光照到的地方偏暖，阴影就偏冷**：

/>

白衬衫的阴影是什么颜色？不是灰，是**淡淡的蓝**，因为天空是蓝的，阴影里装满了天光。写提示词时，加一句「阴影偏蓝紫色而不是黑色」，画面马上干净一截。

### 3. 用饱和度指路

想让观众先看哪里，就让那里的颜色**最鲜艳**，其他地方都压下去：

<CompareGrid
  :cols="1"
  items='[{"src":"/art-lab/i4-focus.webp","label":"整条街是灰蓝，只有伞是红的","change":"背景低饱和，主角高饱和：不用放大，一眼就看到"}]'
/>

如果每样东西都很鲜艳，就等于什么都不突出。

| 配色 | 怎么写 | 适合 |
|---|---|---|
| **同类色** | 整张画只用{蓝}色系，从深到浅 | 安静、下雨天、深海、清晨 |
| **互补色** | {橙}和{蓝}互补：{天空和阴影}是蓝，{夕阳和灯光}是橙 | 热血、名场面、黄昏、海报 |
| **粉彩** | 奶油粉、薄荷绿、浅鹅黄、淡紫，低饱和、高亮度 | 治愈、可爱、甜品、Q 版 |
| **夜晚** | 深蓝和蓝黑为主，只有{窗户和路灯}是暖黄色 | 孤独、思念、夜景壁纸 |
| **霓虹** | 深紫黑的夜，粉紫和青蓝两种霓虹，高饱和，地面反光 | 赛博朋克、都市、游戏 |
| **复古** | 褪色的芥末黄、砖红、墨绿和米白，低饱和 | 怀旧、旧城、Lo-fi 封面 |

::: tip 常用的互补色对
**橙 + 蓝**（动漫最爱：夕阳和天空）、**红 + 青绿**（圣诞、中式）、**黄 + 紫**（魔法、星空）。互补色放在一起最有冲击力，但最好一种多、一种少，别五五开。
:::

## 配色卡模板

把 `{}` 换成你的，放在提示词的画风后面：

```text
配色：以{主色，比如傍晚天空的蓝紫色}为主（大约六成），{辅色}为辅，
{最想让人看的东西}是全画面最亮的{点缀色}；
阴影偏{蓝紫色 / 青色}而不是黑色，亮部带{暖橙 / 暖黄}；整体{通透 / 柔和 / 怀旧}。
```

::: warning 两个常见翻车
- 只写「配色好看」「色彩丰富」：模型会把所有颜色都开到最鲜艳，结果就是开头左边那张。
- 写了「黑暗」「阴郁」，阴影就全变成黑色：可以改成「深蓝色的夜」「低饱和的灰蓝色」，暗下来但不脏。
:::

## 这节课记住三句话

- 通透 = **有主次**（主色、辅色、点缀色）+ **暖光冷影** + **阴影不加黑**。
- 想让人看哪里，就让那里**最鲜艳**，其他地方压下去。
- 六种情绪配色：同类色、互补色、粉彩、夜晚、霓虹、复古，按情绪挑一种。
