# I · 视觉基本功

<TrackPage id="i" />

## 这条路线讲什么

AI 能替你画，但**画面好不好，得你自己看得出来、说得清楚**。美术学院的基础课教的就是这件事：形、透视、光影、色彩、构图。这条路线把它们一课一课讲给零基础的人：

1. **先看**：每课从一幅公有领域的名画开始。用灰度、眯眼看、构图线和取色板这些画家的工具去看它。
2. **再懂**：讲清这一课的专业知识，配一组「提示词只改一句」的对比图。
3. **会说**：这个知识点在提示词里怎么写，哪些词有用，哪些是空话。
4. **马上练**：在页面里画一张，AI 老师按题目要求逐项打分，告诉你下一步改哪里。

课内生图登录后每天有免费次数，用完可以换成自己的 Key 继续画（正常计费）。画出来的图只保存在你的浏览器里。

::: info 正在更新
第 3 课「光影与明暗」和第 5 课「构图」已经上线，其余几课陆续推出。全部上线后开放这条路线的结业证书：每个课内练习的 AI 点评都达到及格分即可领取。

## 名画从哪里来

课里的名画来自大都会艺术博物馆的开放获取（Open Access）馆藏，都是公有领域作品，按 CC0 协议开放使用。每幅画下方都有出处链接，可以去博物馆网站看更高清的原图。
