游戏和动画里那些让人「哇」一声的场面：望不到头的老街、直插云霄的高楼、沙漠里像山一样的巨大残骸……它们的共同点是**纵深**：看起来很深、很远、很大。

纸和屏幕明明是平的，深度是怎么「画」出来的？靠三样东西：**透视、空气透视和参照物**。

## 透视：线往哪里跑

离你越远的东西越小，平行的线（路的两边、屋檐、铁轨）在远处会**汇聚到一个点**，这个点叫**消失点**。

| 透视 | 什么时候用 | 感觉 |
|---|---|---|
| **一点透视** | 正对着街道、走廊、铁轨、隧道 | 很深、往里吸，视线被拉到远处 |
| **两点透视** | 站在街角、看一座建筑的转角 | 立体、真实、像在现场 |
| **三点透视** | 仰望高楼、俯瞰深谷 | 极高或极深，有压迫感和眩晕感 |

在提示词里，用「【透视】」开头写清楚是哪一种，再把**效果**写出来：「所有的线都汇聚到画面中央远处的一个点」。

::: tip 和镜头配合
三点透视的仰望，和 [I6 镜头](/i/i6) 里的「虫视」是好朋友；一点透视配上超广角，纵深会更夸张。
:::

## 空气透视：越远越淡、越蓝

你一定注意过：远处的山总是**淡淡的、发蓝的**。因为中间隔着很多空气和水汽，越远隔得越多。画家把这个现象叫**空气透视**：

  :cols="2"
  base="【画风】数字绘画风景。画面内容：一层层的群山，从近处一直到远处。{}"
  items='[{"src":"/art-lab/i2-air-no.webp","label":"没有空气透视：像一张贴纸","change":"远处的山和近处一样清晰、一样深的绿、一样饱和"},{"src":"/art-lab/i2-air-yes.webp","label":"有空气透视：一层层退远","change":"越远越淡、越蓝、越模糊，最远处融进天空，山谷有薄雾"}]'
/>

右边一句话就多出了几十公里的空间。写法：

- **越远越淡**：远处的东西颜色变浅、对比变弱；
- **越远越蓝**（晴天）或**越远越暖**（黄昏时偏橙粉）；
- **越远越模糊**：细节消失，只剩轮廓；
- 加一点**雾、薄雾、尘土、雨**，效果更明显。

## 参照物：大小是比出来的

一座山到底有多大？没有参照，谁也说不清。放一个**小小的、大家都知道有多大的东西**在旁边：人、骆驼、房子、汽车、一只鸟。

## 纵深清单

画一张「很深很远」的图，检查这几样：

| 检查 | 写进提示词 |
|---|---|
| 有没有**近、中、远**三层？ | 近处是{沙丘 / 花 / 栏杆}，中间是{主体}，远处是{山 / 城市} |
| 线往哪里跑？ | 【透视】一点 / 两点 / 三点透视，线汇聚到{哪里} |
| 远处有没有变淡变蓝？ | 【空气透视】越远越淡、越蓝、越模糊，有薄雾 |
| 有没有参照物？ | 一个小小的{人影 / 驼队 / 房子} |
| 有没有前后**重叠**？ | 近处的东西挡住远处的一部分 |

## 这节课记住三句话

- **透视**：线跑向消失点。正对着用一点，街角用两点，仰望俯瞰用三点。
- **空气透视**：越远越淡、越蓝、越模糊，加点雾更明显。
- **参照物**：一个小小的人、骆驼或房子，世界一下就变大了。
