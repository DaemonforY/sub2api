游戏里的宝剑闪着冷光、动画里的玻璃杯透着阳光、表情包里的小动物毛茸茸的想让人摸……这些「看起来就知道是什么做的」感觉，叫**质感**。

只写「玻璃的」「金属的」，模型常常画得像塑料。这节课教你把质感**拆开写**。

## 质感是光画出来的

同一只猫，为什么会变成六种完全不同的东西？因为**光打在不同材质上，表现不一样**。质感就是回答这五个问题：

| 问题 | 意思 | 例子 |
|---|---|---|
| **透不透明？** | 光能不能穿过去 | 玻璃、水全透；冰半透；木头、金属不透 |
| **有没有折射？** | 透过它看后面的东西，会不会变形 | 玻璃、水会让后面的东西弯曲、放大 |
| **反不反射？** | 表面能不能照出周围 | 镜面金属像镜子；木头几乎不反射 |
| **高光什么样？** | 最亮的那一点 | 金属、玻璃：小而锐利的白点；毛绒：没有高光，只有柔和的亮面 |
| **边缘什么样？** | 轮廓是硬是软 | 玻璃边缘一圈亮线；毛绒边缘软而发光；金属边缘锐利 |

所以写质感，不能只写「玻璃的」，要把这几样**表现**写出来，最好再写清**光从哪来**。

## 六种质感速查卡

| 材质 | 写进提示词 |
|---|---|
| **玻璃** | 透明，能透过它看到后面被折射变形的东西，边缘有一圈亮线，表面有窗户形状的反光，光透过它在地上投下彩色光斑 |
| **镜面金属** | 镜面抛光，像镜子一样反射周围的环境，小而锐利的白色高光，暗部很深，冷硬 |
| **拉丝 / 旧金属** | 表面有细细的拉丝纹理或锈迹、划痕，高光被拉成一条模糊的长条 |
| **毛绒** | 柔软蓬松的长毛，轮廓边缘有一圈被背光照亮的发光细毛，没有硬边 |
| **水** | 透明流动，表面有波纹和水珠，里面有气泡，光透过它投下晃动的焦散光纹 |
| **冰** | 半透明，里面有细小的气泡和裂纹，表面有融化的水珠，边缘发出淡淡的蓝光 |
| **木头** | 看得见木纹，温润的哑光，没有反光，暖棕色 |
| **丝绸** | 柔滑的光泽，褶皱处有流动的高光，颜色随角度变化 |

::: tip 两个让质感「立起来」的小技巧
- **逆光或侧逆光**：透明的东西（玻璃、水、冰）和毛茸茸的东西，都是光从后面照来时最好看。
- **放在会被影响的地方**：玻璃的彩色光斑投在白沙上，金属反射出周围的火光，冰在台面上化出一小滩水。质感不只在物体本身，也在它对周围的影响。
:::

## 质感混搭：脑洞的来源

把东西换成**意想不到的材质**，就是一个现成的脑洞：玻璃做的鲸鱼、水做的猫、冰雕的城堡、毛绒的仙人掌、金属的花。[I9](/i/i9) 做壁纸的时候，不妨试试这一招。

## 这节课记住三句话

- 质感是**光画出来的**：透不透明、折射、反射、高光、边缘。
- 写材质要写**表现**，不要只写「玻璃的」「金属的」；再写**光从哪来**，透明和毛茸茸的东西用逆光。
- 把东西换成**意想不到的材质**，就是一个现成的脑洞。
