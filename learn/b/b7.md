学完前面几课，你已经能画出、改好、发布自己的作品了。比赛是检验它们最直接的地方：有明确的主题，有截止时间，有其他创作者一起比，还有奖品。

## 找到比赛

比赛在 HiveGPT 主站的「活动广场」：[hivegpt.cn/contests](https://hivegpt.cn/contests)，主站导航里点「活动」也能进。每个比赛有自己的详情页，标着当前阶段：

| 阶段 | 能做什么 |
|---|---|
| 即将开始 | 先看主题和规则，提前准备作品 |
| 投稿中 | 可以投稿 |
| 投稿与投票中 | 可以投稿，也可以投票 |
| 等待投票 | 投稿已截止，投票还没开始 |
| 投票中 | 只能投票 |
| 计票中 | 投票结束，正在统计 |
| 已结束 | 公布名次 |

**投稿前先读完详情页的「活动规则」和「奖项设置」。**每个比赛的主题、每人能投几个作品、是否审核、奖品都可能不同。

## 三种投稿方式

<figure class="ai-figure"><img src="/learn-img/b/b7-1.webp" alt="三条路径把作品送进比赛入口" width="960" height="640" loading="lazy" /><figcaption>三条路径把作品送进比赛入口<span>AI 生成配图</span></figcaption></figure>

1. **画布作品页**：打开你已发布的作品，点「投稿参赛」，在「用这个作品参加活动」里选活动、选要投稿的图片，填投稿标题和创作说明，点「投稿」。
2. **生图工作台**：生成结果上点「投稿到活动」，选择活动，填作品名称、创作说明和提示词，点「提交投稿」。
3. **比赛页面**：直接「上传图片」，或者「从画布作品选择」。

创作说明值得认真写：主题怎么理解的、用了哪些步骤（比如先生图，再局部编辑，最后扩图），投票的人会看。

## 投稿规则和常见的坑

- 只能在投稿时间内投稿；每人能投几个作品由每个比赛单独规定。
- 图片支持 PNG、JPEG、WebP、GIF，不超过 10MB。
- 同一个作品不能重复投稿。
- 仅自己可见的作品、还在审核中的作品不能投稿，想参赛的作品发布时选「公开」。
- 有的比赛会审核投稿，审核期间显示「审核中」。
- 投稿截止前可以「撤回作品」，换一张更好的。

::: warning 内容规则
真实人物、国旗国徽等国家标志、政治、暴力、成人内容会被拦截，也不能用于投稿。作品要如实说明是 AI 生成的，不要冒用别人的作品。
:::

## 投票

每个比赛里每人有一定的票数，页面上会显示「你还剩 X / Y 票」。点「投票」投给喜欢的作品，改主意了可以「取消投票」。

- 一般不能给自己的作品投票；
- 有的比赛要求账号注册满一定时间才能投票。

## 名次怎么定

<figure class="ai-figure"><img src="/learn-img/b/b7-2.webp" alt="投票代币决定作品名次排序" width="960" height="640" loading="lazy" /><figcaption>投票代币决定作品名次排序<span>AI 生成配图</span></figcaption></figure>

比赛没有评委，**名次按公开投票的票数排**，投票结束后统计。票数相同时，先达到这个票数的排前面；再相同，就看谁投稿更早。

每个名次的奖品可能是账户余额，也可能是活动自定的奖品，以各比赛的「奖项设置」为准。

## 小结

- 比赛在主站的「活动广场」，先看阶段，再读「活动规则」和「奖项设置」。
- 可以从画布作品页、生图工作台或比赛页面投稿；私密和审核中的作品不能投，截止前可以撤回。
- 没有评委，名次按公开票数排，票数相同时先达到的排前面。

学完这条路线后，到路线页领取结业证书，结业要求是在画布社区公开发布至少 3 个作品。
