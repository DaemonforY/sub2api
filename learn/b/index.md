# B · AI 绘画与视频创作

<TrackPage id="b" />

## 这条路线讲什么

AI 画图的门槛不在工具，而在**怎么把脑子里的画面说清楚**。这条路线用 HiveGPT 无限画布（[canvas.hivegpt.cn](https://canvas.hivegpt.cn)）边学边画：

1. **提示词的结构**：把「一只猫」写成模型能画好的描述。
2. **提示词模板**：站内的提示词库按场景整理好了大量可直接用的模板，学会改模板比从零写快得多。
3. **参考图和图生图**：给一张图，让模型保留什么、改什么。
4. **局部编辑、扩图和抠图**：只改画面的某一块，把画面往外扩，把主体单独抠出来。
5. **视频生成**：在视频创作台用文字或参考图生成短视频。
6. **发布作品和做同款**：把作品发到画布社区，用别人公开的提示词做同款。
7. **参加比赛**：在活动广场投稿、拉票，看看大家怎么画。

画布用 HiveGPT 账号登录即可使用，生图按次计费，用的是你账户里的余额或订阅。

## 结业

满足下面的条件，可以在本页领取这条路线的结业证书：

- 学完 7 课；
- 各课测验总正确率 ≥ 80%；
- 完成检查点：在画布社区公开发布一个作品（B6 里有）；
- 结业项目：在画布社区公开发布至少 3 个作品（需要审核的作品通过后计入），证书上会附上你的画布主页。
