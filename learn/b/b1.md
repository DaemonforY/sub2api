同样是「画一只猫」，有人得到一张随手拍，有人得到一张能当海报的插画。差别几乎全在提示词：**模型只会画你说清楚的东西，没说的部分它会自己猜。**

## 六个部分

<figure class="ai-figure"><img src="/learn-img/b/b1-1.webp" alt="六个模块像积木组成提示词" width="960" height="640" loading="lazy" /><figcaption>六个模块像积木组成提示词<span>AI 生成配图</span></figcaption></figure>

一段好用的画图提示词，通常包含这几块（不用每次都写全，但要知道缺了哪块）：

| 部分 | 回答的问题 | 例子 |
|---|---|---|
| 主体 | 画什么？长什么样、在做什么？ | 一只橘色短毛猫，趴在窗台上，看着窗外 |
| 场景 | 在哪里、什么时间？ | 下雨的傍晚，老式木窗，窗外是街道 |
| 风格 | 照片还是插画？哪种画风？ | 温暖的水彩插画 / 胶片摄影 |
| 构图 / 镜头 | 远景还是特写？什么角度？ | 侧面中景，猫在画面左侧三分之一处 |
| 光线和色彩 | 光从哪来？整体色调？ | 室内暖黄色台灯光，窗外冷蓝色调 |
| 细节和画质 | 还有什么要特别注意的？ | 玻璃上有雨滴，毛发细节清晰，竖版构图 |

把它们连起来：

> 一只橘色短毛猫趴在老式木窗的窗台上，侧脸望向窗外下雨的街道。傍晚，室内有暖黄色台灯光，窗外是冷蓝色调，玻璃上挂着雨滴。温暖的水彩插画风格，侧面中景，猫位于画面左侧三分之一处，毛发细节清晰，竖版构图。

## 有用的词和没用的词

<figure class="ai-figure"><img src="/learn-img/b/b1-2.webp" alt="具体词像工具，空泛词像泡泡" width="960" height="640" loading="lazy" /><figcaption>具体词像工具，空泛词像泡泡<span>AI 生成配图</span></figcaption></figure>

- **有用**：具体的名词和形容词（「橘色短毛」「老式木窗」）、明确的风格（「水彩」「胶片摄影」「3D 黏土风」）、镜头语言（「特写」「俯拍」「广角」）、光线（「逆光」「侧光」「黄昏」）。
- **没用或作用很小**：「高清」「8K」「杰作」「最好的质量」这类空泛的夸奖词，现在的模型基本不靠它们提升画质。与其堆这些，不如把主体和光线写具体。
- **容易出问题**：一段里塞好几个互相矛盾的风格（「写实照片风格的卡通」），模型会左右为难。

::: tip 中文还是英文？
画布里用的 `gpt-image-2` 能直接理解中文提示词，用你最能说清楚的语言写就好。
:::

## 在画布里画出来

把改写好的提示词放进 HiveGPT 无限画布的生图工作台就能出图。下面这条可以直接试：

画出来以后，试着**每次只改一个部分**（比如只把「水彩插画」换成「胶片摄影」），对比效果。这是摸清提示词规律最快的办法。

::: warning 这些内容会被拦截
真实人物（尤其公众人物）、国旗国徽等国家标志、政治、暴力、成人内容，会触发模型的内容安全审核。被拦截的请求 HiveGPT 不扣费，换一种描述再试。
:::

## 小结

- 主体、场景、风格、构图、光线色彩、细节，缺哪块模型就会自己猜哪块。
- 少堆「高清 8K 杰作」，多写具体的名词、镜头和光线。
- 一次只改一个部分，对比着学。
