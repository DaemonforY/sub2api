# AI 生成电商产品图

**有实物照片时用「图生图」：上传商品照片，写清楚「保留商品本身不变，把背景换成……」；没有照片时用文字描述商品，做概念图和场景图。** 主图要干净（白底或简单背景），场景图要写清楚商品放在哪、光从哪来、什么风格。

> 更新于 2026-10，基于 gpt-image-2。参考图的用法见 [B3 · 参考图和图生图](/b/b3)。

## 用自己的商品照片换背景（最常用）

在无限画布的生图工作台里，把商品照片拖进「参考图」，它会被标成「图片1」，然后这样写：

**白底主图**

<TryInCanvas prompt="保留图片1 中的商品本身，形状、颜色、材质和标签文字都完全不变。把背景换成纯白色，商品居中，正面平视，柔和均匀的棚拍光，商品下方有自然的淡淡阴影，电商白底主图，1:1 构图。" />

**场景图**

<TryInCanvas prompt="保留图片1 中的商品本身，形状、颜色和标签文字完全不变。把它放在浅色大理石台面上，旁边点缀几片绿叶和一块柔软的亚麻布，清晨窗边的自然侧光，浅景深，高级的生活方式产品摄影风格。" />

**节日氛围图**

<TryInCanvas prompt="保留图片1 中的商品本身完全不变。把背景换成温暖的圣诞氛围：木桌上有松枝、红色丝带和小礼物盒，背景是虚化的暖黄色灯串光斑，商品是画面的视觉中心，商业广告摄影风格。" />

::: tip 商品被改了怎么办
- 在「保留」里多写几项：**形状、颜色、材质、标签文字、瓶盖、logo 位置**。
- 标签上的字被改花：再加一句「标签上的文字保持原样，不要重新绘制」。
- 还是会变：先只换背景，商品本身用局部编辑保护，见 [B4 · 局部编辑](/b/b4)；或者先 [抠图](/b/b4)，再把抠好的商品放到新背景上。
:::

## 尺寸怎么选

| 用途 | 建议比例 | 说明 |
|---|---|---|
| 淘宝 / 京东主图 | 1:1 | 白底图、首图 |
| 详情页长图 | 3:4 或 2:3 | 竖版，多张拼接 |
| 小红书笔记 | 3:4 | 见 [封面提示词](/prompts/cover) |
| 横幅广告 | 16:9 或 21:9 | 横版，留出放文字的空白 |

在生图工作台的「图像设置」里选比例和质量。先用低质量试构图，满意了再用高质量出最终图。

## 注意事项

- **AI 图要标注。** 平台对 AI 生成的商品图有标注要求，发布前看清所在平台的规则；AI 图不能用来夸大或虚构商品的真实效果。
- **不要用别人的品牌和商标。** 只用自己有权使用的商品照片和 Logo。
- **真人模特图要谨慎。** 不要用真实人物的照片生成「代言」效果。

更多场景的提示词见 [gpt-image-2 提示词大全](/prompts/)。
