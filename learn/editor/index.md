# 公众号排版使用教程

[公众号排版](https://hivegpt.cn/editor/) 是一个网页工具：左边写 Markdown，右边就是文章在公众号里的样子。它能做三件事：

- **排版**：19 种风格随点随换，一键复制到公众号后台。不用登录，免费。
- **导入与 AI**：贴公众号文章链接导入；让 AI 润色、精简、扩写、拟标题、写摘要，画插图和封面。需要登录 HiveGPT，AI 费用记在你自己的 Key 上。
- **发到草稿箱**：填好公众号的 AppID / AppSecret 后，图片、封面、正文一键发进草稿箱，到公众号后台检查后就能群发。

![公众号排版的主界面：左边 Markdown，右边公众号预览](/editor-img/main.webp)

::: tip 只想排版？
不需要任何配置：写好后点右上角「复制到公众号」，到公众号后台新建图文，粘贴即可。下面的 AppID、白名单只有「发送到草稿箱」才用得到。
:::

## 快速开始

1. 打开 [hivegpt.cn/editor](https://hivegpt.cn/editor/)，电脑上用效果更好。
2. 左边写 Markdown，或从飞书、Notion、Word 直接粘贴（会自动转成 Markdown）；也可以点「上传 MD 文件」。
3. 在顶部「选择样式」里点一个风格，右边实时预览。喜欢的风格可以点 ☆ 收藏。
4. 发出去：
   - 点「复制到公众号」，到公众号后台粘贴；或者
   - 点「发送到草稿箱」，直接进公众号的草稿箱（先按[下一节](#setup)配置一次）。

第一次打开页面时，左下角有一张上手引导卡片，点「知道了」后不再出现。

![首次打开时的上手引导](/editor-img/welcome.webp)

## 配置公众号：AppID、AppSecret 和 IP 白名单 {#setup}

「发送到草稿箱」要用公众号的开发接口，需要三样东西。微信已经把「开发接口管理」从公众平台搬到了**微信开发者平台**，下面按新入口来。

::: warning 需要公众号管理员操作
登录开发者平台、获取或重置 AppSecret 都需要公众号**管理员**的微信扫码。如果你是运营者，请管理员帮忙做第 1～4 步。
:::

### 1. 登录微信开发者平台

打开 [developers.weixin.qq.com/platform](https://developers.weixin.qq.com/platform/)，用管理员的微信扫码登录。

### 2. 复制 AppID

进入「**我的业务 → 公众号**」，点开你的公众号，在「**基础信息**」里能看到 **AppID**：`wx` 开头的 18 位字符，直接复制。

### 3. 获取 AppSecret

同一页的「**开发密钥**」里管理 **AppSecret**（开发者密码，32 位）：

- **第一次用**：点「启用」，管理员扫码确认后复制密钥。
- **以前生成过但忘了**：平台不会再显示已生成的密钥，只能点「重置」生成新的。
- **已经在别的工具里用着**：可以直接填同一个密钥，不必重置。

::: danger 重置前想一想
重置后旧密钥立刻作废，所有用旧密钥的工具（第三方编辑器、自己写的脚本等）都要换成新的。复制后请自己妥善保存。
:::

### 4. 把服务器 IP 加入 API IP 白名单 {#whitelist}

同样在「**开发密钥**」处，找到「**API IP 白名单**」点「编辑」，加入：

```text
43.133.80.169
```

这是 HiveGPT 服务器调用微信接口时用的 IP。保存后**等几分钟**生效。

- 白名单是整个公众号共用的，**原有的 IP 不要删**，在后面追加即可。
- 不在白名单时，「测试连接」会提示「服务器 IP 不在公众号的 API IP 白名单里」，并告诉你微信看到的 IP。

### 5. 在排版页添加公众号

打开排版页的「设置」（或直接打开 [hivegpt.cn/editor/#settings](https://hivegpt.cn/editor/#settings)），点「添加公众号」，填备注名、AppID、AppSecret，点「**测试连接**」。看到「连接成功」就可以保存了。设置里也有同样的分步说明和 IP 复制按钮。

![设置页：公众号账号和接入指引](/editor-img/settings.webp)

可以添加多个公众号，用「默认」选发送时默认用哪个。

::: details 找不到「我的业务」或开发者平台？
部分老账号仍可在公众平台（mp.weixin.qq.com）「设置与开发 → 开发接口管理 → 基本配置」里找到 AppID、AppSecret 和 IP 白名单；微信正在逐步迁移，两边找不到时以开发者平台为准。官方说明见[公众号「开发接口管理」升级说明](https://developers.weixin.qq.com/doc/subscription/guide/dev/migration.html)。
:::

## 发送到草稿箱

1. 登录 HiveGPT（右上角「登录」，登录后自动回到排版页）。
2. 写好文章、选好风格，点「**发送到草稿箱**」。
3. 填写：
   - **标题**（必填，默认取文章第一个标题）、作者、摘要（可以让 AI 写）、原文链接、是否开启留言。
   - **封面**（必填）：从文章图片里选、上传，或让 AI 生成。会自动裁成公众号封面的 2.35:1。
4. 点发送。工具会把正文图片上传到微信、把封面存为永久素材，再建好草稿。
5. 到公众号后台的「**草稿箱**」里打开草稿，用手机预览确认后再群发。

关于图片：

- 正文图片微信只收 **jpg / png 且小于 1MB**，工具会自动压缩。
- **GIF 动图**微信接口不接受，会跳过并提示，请在公众号后台手动补上。
- 封面最大 10MB。

## 导入公众号文章

点顶部「导入文章」（或打开 [hivegpt.cn/editor/#import](https://hivegpt.cn/editor/#import)），粘贴 `https://mp.weixin.qq.com/s/...` 形式的文章链接。正文会转成 Markdown，图片一起下载到本地，之后可以换个风格重新排版、改写后再发。

- 需要登录 HiveGPT。
- 只支持 mp.weixin.qq.com 的文章链接。请只导入你自己或有权转载的文章。

## AI 润色与配图

点顶部「AI 助手」打开侧栏。第一次用先在「设置 → AI Key」里选一个 Key：只列出 **GPT 分组**的 Key，没有就去 [我的 Key](https://hivegpt.cn/keys) 创建一个（分组选「GPT-按量」或你已订阅的 GPT 分组）。

**文字**：润色、精简、扩写、拟 5 个标题、写摘要、列提纲，或者写自己的要求。先在左边选中一段就只改这一段，不选就处理全文。结果边生成边显示，可以替换、插入或复制。

**配图**：用 gpt-image-2 画，可选日系二次元、扁平插画、水彩、写实摄影、科技感 3D 等风格，也能根据选中的段落自动写画面描述。图下默认注明「AI 生成配图」，也可以直接设为封面。

费用按所选 Key 的分组计费，每次调用都能在 HiveGPT「使用记录」里查到。

## 安全说明

- **AppSecret 只保存在你的浏览器里**（localStorage）。发送时随请求交给 HiveGPT 服务器，服务器只用它向微信换取调用凭证，凭证在内存里缓存约 2 小时，不写数据库、不记日志。
- 在**公用电脑**上用完，请在「设置」里删除公众号账号。
- 怀疑 AppSecret 泄露：到开发者平台「开发密钥」点「重置」，旧密钥立刻失效；也可以先「冻结」（约 10 分钟生效）。
- 即使别人拿到了你的 AppSecret，不在白名单里的 IP 也调不了你的公众号接口。

## 常见问题 {#faq}

| 提示 | 原因和处理 |
|---|---|
| 服务器 IP … 不在公众号的 API IP 白名单里（40164） | 按[第 4 步](#whitelist)加入 `43.133.80.169`，等几分钟再试 |
| AppSecret 不正确，或已经重置过（40125 / 40001） | 重新复制 AppSecret；如果刚重置过，用新的那个 |
| AppSecret 已被冻结（40243） | 到「开发密钥」解冻，约 10 分钟后生效 |
| AppID 不正确（40013） | 到「基础信息」重新复制，注意是 `wx` 开头的 18 位 |
| 这个公众号没有该接口权限（48001） | 见下方「个人号能用吗」 |
| 调用太频繁或已到今日上限（45009） | 微信对每个公众号有每日调用次数限制（新建草稿每天 1000 次），明天再试 |
| 图片格式或大小不符合要求 | 正文图片需 jpg / png 且小于 1MB；GIF 请到公众号后台手动上传 |
| 请先登录 HiveGPT | 导入、发草稿箱、AI 都需要登录；排版和复制不需要 |

**个人号、未认证的公众号能用吗？**
可以先试。微信文档里「新建草稿」和素材接口对订阅号开放，但有部分个人或未认证账号实际调用会返回 48001（没有接口权限）。2025 年 7 月起，个人主体和未认证账号已不能通过接口**发布**文章，所以本工具只负责把文章送进草稿箱，群发请在公众号后台手动操作。接口权限可以在开发者平台「我的业务 → 公众号 → 接口管理 → 接口权限与额度」查看。遇到 48001 时，用「复制到公众号」粘贴到后台同样能保留排版。

**连接成功了，发送时却提示 IP 不在白名单？**
白名单修改要几分钟才生效；另外请确认加的是 `43.133.80.169`，并且没有把它和别的 IP 写在同一行。

**草稿里的排版和预览不一样？**
公众号会过滤部分样式（例如某些动画、外部字体）。发送前可以换一个风格对比；草稿建好后在手机上预览为准。

**能在手机上用吗？**
能打开，但左右分栏在手机上很挤，建议用电脑编辑。
