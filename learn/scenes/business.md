# 小老板与个体户

小店没有专门的文案、客服、行政、财务，所有事都是老板自己扛。AI 相当于一个不要工资的助理：写东西、想点子、整理表格都能先帮你做一版。

[[toc]]

## 客服话术和常见问题

**以前**：同样的问题一天回答几十遍，每个人回答得还不一样。

**用 AI**：把你遇到过的问题和你的规矩告诉它，整理出一份标准回复，店员照着用。

```text
我开了一家网店卖手工香薰蜡烛。下面是顾客常问的问题和我平时的回答（很零散）。
请整理成一份「客服常见问题手册」：
- 按「发货物流、商品使用、售后退换、定制」分类
- 每个问题给一个标准回复，语气亲切但不要太腻，不超过 60 字
- 我没说清楚的规则（比如定制能不能退），用【待老板确认】标出来，不要自己编

【零散记录】
问多久发货：一般 48 小时，节假日会慢
问能不能刻字：可以，加 10 块，要多等 3 天
问蜡烛能烧多久：大号 40 小时左右
问碎了怎么办：拍照给我们补发
……
```

## 商品标题和详情

```text
帮我写一款商品的详情页文案。
商品：手工皂，橄榄油和乳木果油，冷制工艺，100 克，适合干性皮肤。
目标顾客：25–40 岁、注重成分的女性。
请写：
1. 3 个商品标题（30 字以内，包含主要关键词）
2. 5 条卖点，每条一句话
3. 一段 150 字的商品故事
4. 使用方法和注意事项
要求：只写我提供的真实信息，不要写「治疗」「祛痘」「美白」等功效宣称，不用「最好」「第一」等绝对化用语。
```

::: warning 功效宣称有法律风险
化妆品、食品、保健品的宣传有严格规定，AI 写的文案可能带出违规的功效词。发布前对照平台规则检查一遍，拿不准的词就删掉。
:::

商品图片：可以在 [AI 画布](https://canvas.hivegpt.cn/?utm_source=learn) 里做场景图、换背景、出海报。但商品本身的样子要真实，不能让顾客收到货觉得「和图不一样」。

## 合同初审

**以前**：房租合同、供货合同、加盟合同，看不懂也只能硬着头皮签。

**用 AI**：让它帮你**找出需要注意的条款，列出要问的问题**。

```text
我是一个小餐馆老板，下面是店面租赁合同。我不是法律专业的。
请帮我：
1. 用大白话总结这份合同的主要内容（租金、期限、押金、违约）
2. 找出对我（承租方）可能不利的条款，说明为什么
3. 列出签约前我应该和房东确认或要求修改的问题
4. 哪些地方建议我找律师看
不要给出「可以签」或「不能签」的结论。

（粘贴合同，身份证号、银行账号可以先删掉）
```

::: danger 重要合同请找律师
AI 可能看漏条款，也不了解当地的具体规定和你的实际情况。金额大、期限长的合同（店面租赁、加盟、合伙、借款），请让律师审核后再签。AI 的作用是让你**带着问题**去找律师，节省沟通时间。
:::

## 日常经营

| 事情 | 提示词示例 |
|---|---|
| 排班 | 「5 个员工，每周营业 7 天、每天两班，每人每周休 2 天，小王周三不能上班。帮我排一个公平的班表，用表格」 |
| 招聘 | 「写一条招聘服务员的朋友圈，写清楚工作时间、待遇范围（我会填）、要求，语气真诚」 |
| 节日活动 | 「我开奶茶店，七夕想做个小活动，预算不多，给我 5 个点子，各写需要准备什么」 |
| 店员培训 | 「把下面这些开店、闭店的注意事项整理成一张检查清单，每项能打勾」 |
| 回复合作邀约 | 「有人想来店里拍探店视频，要我免单，我想拒绝但保持友好，帮我回复」 |

## 用 Codex 处理一堆文件

网店经常会遇到这种批量的活：

- 几百张商品图要统一改尺寸、加水印、按货号重命名
- 每天从平台导出订单表，要整理成发货单
- 几个平台的销售表要合并起来看

这些不用一个个手动弄，交给 Codex，它会在你电脑上写个小工具帮你批量做。例如：

```text
这个文件夹里有 300 多张商品图（jpg、png 都有），文件名是乱的。
请帮我：
1. 全部统一成 800×800 的白底 jpg（不够正方形的四周补白，不要拉伸变形）
2. 在右下角加上半透明文字水印「小满手作」
3. 按「货号对照.xlsx」里的对应关系重命名
4. 结果放到新文件夹「处理后」，原图不要动
先处理 5 张给我看效果，我确认后再处理全部。
```

怎么开始用 Codex、它会问你哪些权限、怎么保证安全，见 [自动化入门](/scenes/automation) 和 [批量处理文件和表格](/scenes/automation-files)。

## 注意事项

- **顾客信息**：订单里的姓名、手机号、地址不要贴给 AI；用 Codex 处理订单表时，在副本上操作，处理完把不需要的副本删掉。
- **价格和承诺**：AI 写的客服话术里可能出现你没打算给的优惠或保证，用之前逐条看。
- **真实宣传**：商品描述、评价、销量都要真实，不要让 AI 编造好评。
