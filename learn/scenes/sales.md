# 销售与运营

销售和运营每天要面对大量「写」和「想」：给不同客户写不同的话、想活动点子、看数据找原因。AI 擅长快速出多个版本，帮你把思路打开。

[[toc]]

## 客户跟进话术

**以前**：每个客户都发差不多的消息，或者对着一个沉默了两周的客户，不知道怎么开口。

**用 AI**：把客户情况讲清楚，让它按你的风格写几个版本。

```text
我是做企业培训课程的销售。客户情况：
- 某制造企业的 HR 经理，上个月聊过一次，对「新员工管理培训」有兴趣
- 当时说要等年中预算，之后两周没回消息
- 他们公司最近在招聘很多一线主管

帮我写 3 条微信跟进消息，每条不超过 80 字：
1. 用一条行业资讯或干货开头，不直接推销
2. 关心他们最近的招聘情况，自然带出课程
3. 直接但礼貌地问预算进展
不要用「亲」「您好呀」这类过于营销的口吻。
```

## 竞品整理

**以前**：打开十几个网页，复制粘贴到一个表里，格式乱七八糟。

**用 AI**：你把收集到的资料（官网介绍、报价单、宣传册文字）贴给它，让它整理成对比表。

```text
下面是我收集的三家竞品的资料。请整理成对比表格，维度：目标客户、主要功能、价格方式（只写资料里有的）、宣传的卖点、明显的短板。
资料里没有的写「资料未提及」，不要自己补充或猜测。
最后写一段：和这三家相比，我们（产品介绍附在最后）可以重点强调的 3 个差异点。

【竞品 A 资料】……
【竞品 B 资料】……
【竞品 C 资料】……
【我们的产品】……
```

::: warning AI 不知道最新的竞品信息
模型的知识有截止时间，也可能记错。竞品的价格、功能以对方官网和你实际拿到的资料为准；让 AI 只根据你给的材料整理，不要让它「凭记忆」介绍竞品。
:::

想让 AI 自己去打开几十个网页、把内容抓下来整理成表，见 [网页整理与浏览器操作](/scenes/automation-web)。

## 活动方案

**以前**：照抄去年的方案改改日期。

**用 AI**：先让它问你问题，再出方案，最后让它自己挑毛病。

```text
我在一个社区开了家烘焙店，想在中秋节前做一次促销活动。
先别给方案，先问我 6 个你需要知道的问题（比如预算、目标、人手），一次问完。
我回答后，给我 3 个不同思路的方案，每个包含：活动形式、准备清单、时间安排、预计成本项（不需要具体数字，列出要花钱的地方）、怎么判断效果。
```

方案出来后，接着问：

```text
站在一个只有两个员工的小店的角度，这三个方案里哪些环节最容易出问题？怎么简化？
```

## 数据复盘

**以前**：数据导出来了，但看不出个所以然，复盘报告写成流水账。

**用 AI**：把数据贴给它（几十行以内），让它先找规律，你再结合实际情况判断。

```text
下面是我们店铺最近 8 周的运营数据（Tab 分隔，从 Excel 复制）。
请帮我：
1. 指出最明显的 3 个变化（上升或下降），写清楚是哪周、变化了多少
2. 对每个变化给出 2–3 个可能的原因，标明哪些需要我去核实
3. 建议下个月重点盯哪 2 个指标

注意：只根据数据说话，可能的原因要写成「可能」，不要写成定论。

（粘贴数据）
```

数据量大（几千行订单明细、多个月份的文件），让 Codex 直接读文件算，见 [财务与数据](/scenes/data)。

## 写各种文案

| 要写的 | 提示词要点 |
|---|---|
| 朋友圈、社群推广 | 给 2 句你满意的旧文案当例子；说清楚卖点和目标人群；要多个版本 |
| 产品介绍、详情页 | 列出产品真实参数；说清楚读者是谁；要求「不用绝对化用语」 |
| 客户案例 | 给出客户原话和真实数据；要求按「问题 → 方案 → 结果」写 |
| 直播、电话话术 | 让它写开场、介绍、应对 5 种常见拒绝、收尾 |

::: warning 广告用语要合规
「最好」「第一」「100% 有效」「国家级」这类绝对化用语，广告法有明确限制。可以在提示词里直接写「避免使用绝对化用语和无法证明的承诺」，发布前自己再检查一遍。
:::

## 注意事项

- **客户的姓名、电话、公司名**：贴给 AI 前换成代号，例如「客户 A，某制造企业」。
- **不要让 AI 编数据和案例**：客户评价、成交数据、行业排名必须是真的。
- **报价、合同条款、折扣承诺**：AI 写的话术里可能带出你没打算给的承诺，发之前逐句看。
