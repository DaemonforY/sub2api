# 财务与数据

和数字打交道的工作，AI 能帮上两类忙：

- **教你怎么做**：Excel 公式不会写、透视表不会做，问它。
- **直接帮你做**：几千行、几十个文件的数据，让 Codex 在你电脑上直接读、算、出结果。

## 写 Excel 公式

**以前**：搜「Excel 怎么……」，看半天教程，套到自己表里又报错。

**用 AI**：描述清楚你的表长什么样、要算什么。

```text
我的 Excel 表：
- A 列是日期（2024-03-05 这种格式），B 列是销售员姓名，C 列是金额
- 一共 2000 行左右
我想在另一张表里，按「销售员 + 月份」汇总金额。
请给我公式（我用的是 WPS / Excel 2016，没有 FILTER 函数），说明每部分的意思，再告诉我常见的出错原因。
```

## 清洗格式混乱的数据

几十行以内的数据，直接从表格里复制贴给 AI（复制出来是 Tab 分隔的），让它整理好再贴回去。具体提示词见 [办公室日常 · 整理表格](/scenes/office#整理表格)。

数据再多，贴进对话框就不靠谱了：容易被截断，AI 也可能漏掉、改错几行而你看不出来。这时候换一种思路：**不让 AI 直接改数据，而是让它写一个处理数据的小程序，程序来改**。程序处理一万行和一百行一样准，还能重复用。Codex 就是干这个的。

## 用 Codex 直接处理电脑里的 Excel

Codex 是一个能在你电脑上干活的 AI：读文件、写小程序、运行它、检查结果。你只需要用中文说清楚要什么。安装和接入见 [安装 Codex CLI 并接入 HiveGPT](/c/c1)，第一次用建议先读 [自动化入门](/scenes/automation)。

### 例 1：合并几十个格式一样的表

各门店、各月份交上来一堆 Excel，要合成一张总表：

1. 新建一个文件夹，比如 `门店汇总`，把所有 Excel **复制**进去（原件留着别动）。
2. 在 Codex 里打开这个文件夹（桌面应用：添加项目选这个文件夹；命令行：在这个文件夹里运行 `codex`）。
3. 把下面的话发给它：

```text
这个文件夹里有 30 多个门店的销售表（.xlsx），格式基本一样，但有几个表的列顺序不同、个别表多了空行。
请帮我：
1. 先读几个文件，告诉我你看到的表头和格式差异，等我确认后再继续
2. 把所有表合并成一张「汇总.xlsx」，加一列「门店」，值取自文件名
3. 去掉完全空白的行，金额统一成数字格式
4. 合并完告诉我：一共处理了几个文件、多少行；哪些文件有异常（打不开、缺列）
不要修改原来的文件。
```

### 例 2：对账

```text
文件夹里有两个文件：「银行流水.xlsx」和「系统订单.csv」。
请按金额和日期（允许相差 1 天）把两边对上，输出「对账结果.xlsx」，分三个工作表：
- 两边都有且对上的
- 只在银行流水里有的
- 只在系统订单里有的
对不上的每一笔，在备注里写可能的原因（比如金额相同但日期差 2 天以上）。最后告诉我三类各有多少笔、金额合计多少。
```

### 例 3：出汇总表和图表

```text
读「2024 年订单明细.xlsx」，帮我做一份月度分析：
1. 每月的订单数、销售额、客单价
2. 销售额前 10 的商品
3. 画两张图：每月销售额折线图、各品类占比饼图，保存成 png
4. 把以上结果写进一个新的「月度分析.xlsx」，图表插在第二个工作表
做完后用几句话告诉我最值得注意的变化。
```

### Codex 干活时你会看到什么

- 它会先**读文件、看结构**，有时会问你确认。
- 它会写一个小程序（通常是 Python）来处理数据，然后运行。
- 电脑上缺处理 Excel 的工具时，它可能会**请求联网安装**（比如安装 Python 的表格库），这一步会弹窗等你批准。看清楚是安装什么再同意。
- 做完后它会告诉你结果文件在哪、处理了多少行。

::: warning 一定要抽查结果
AI 写的程序跑出来的结果，**拿几行手算对一下**：随机挑 3–5 行和原表对比，合计数和原表的合计对一下。第一次处理某种表格时尤其要仔细。对得上，以后同样的表就可以放心用同一个程序了，让 Codex 把程序留下来，下次说「用上次那个程序处理这个月的表」就行。
:::

## 读懂报表

拿到一份财务报表、经营报表看不懂，让 AI 帮你解读：

```text
我不是财务出身。下面是我们公司上季度的利润表（数字已按比例缩放）。
请：
1. 用大白话解释每一大项是什么意思
2. 指出和上季度相比变化最大的 3 项
3. 列出我在下次经营会上可以问财务的 5 个问题
不要做投资判断。

（粘贴报表）
```

## 注意事项

- **敏感数据先脱敏**：工资、客户账户、未公开的财务数据，贴给 AI 前删掉或替换；公司有数据安全规定的，先问清楚能不能用。用 Codex 处理本地文件时，它读到的内容也会发给模型。
- **原始文件留底**：永远在副本上操作，要求 Codex「不要修改原文件，结果另存新文件」。
- **数字要核对**：AI 的心算不可靠，涉及计算一律让它写程序算或者用 Excel 公式算，不要相信它直接「说」出来的合计数。
- **涉及报税、审计、投资的判断**：AI 只能帮你整理和解释，结论请找会计师、税务师。
