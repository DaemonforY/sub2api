# 批量处理文件和表格

这一篇是几个最常见的批量任务，每个都可以直接照着做。第一次用 Codex 的话，先看 [自动化入门](/scenes/automation) 了解怎么准备、怎么批准操作。

所有任务通用的三条：

1. **把文件复制到一个专门的工作文件夹**，在这个文件夹里打开 Codex。
2. 指令里写明**「不要修改或删除原文件」**，结果放到新文件夹。
3. 指令里写明**「先做几个给我看，我确认后再全部做」**。

## 整理乱糟糟的文件夹

「下载」文件夹、桌面，堆了几百个文件，找什么都找不到。

```text
这个文件夹里有几百个各种文件。请帮我整理：
1. 先统计一下有哪些类型的文件、各有多少个，告诉我你打算怎么分类，等我确认
2. 按类型分到子文件夹：文档（Word、PDF、txt）、表格（Excel、csv）、图片、视频、压缩包、安装包、其他
3. 文档和表格再按修改时间分到「年-月」子文件夹
4. 找出内容完全相同的重复文件，列出清单给我看，不要删除
5. 整理完生成一个「整理记录.txt」，写清楚每个文件从哪移到了哪，万一需要可以还原
```

**它会做什么**：先列出文件统计，等你确认后写一个小程序来移动文件。找重复文件是比较文件内容（不是只看名字），比较准确。

**要注意**：「移动」和「删除」不一样，移动可以还原。重复文件让它**只列清单**，你自己决定删哪个。

## 批量重命名

```text
这个文件夹里是 2023 年所有的报销发票扫描件（PDF），文件名是扫描仪自动起的。
请读取每个 PDF 里的内容，按「日期_开票方_金额.pdf」重命名，比如「2023-03-05_某某餐饮_268.00.pdf」。
- 读不出来的（比如扫描得太模糊），文件名不动，最后列出清单给我
- 先处理 3 个给我看
- 另外生成一张「发票清单.xlsx」，列出日期、开票方、金额、原文件名、新文件名
```

**它可能请求的权限**：读 PDF 需要专门的工具库，如果你电脑上没有，它会请求联网安装（比如 Python 的 pypdf）。扫描件是图片，需要文字识别（OCR），它可能会提议安装额外的识别工具，安装体积可能比较大，你可以先问它要装什么、有没有更简单的办法。

::: warning 识别结果要核对
扫描件的文字识别不可能百分之百准确，金额、日期尤其要抽查。用于报销、记账的数字，以发票原件为准。
:::

## Word / PDF 批量转格式

```text
这个文件夹里有 50 多份 .doc 和 .docx 格式的产品说明书。
请帮我：
1. 全部转成 PDF，放到「PDF版」文件夹
2. 再全部转成 Markdown 纯文本，放到「文本版」文件夹（方便我以后丢给 AI 处理）
3. 告诉我哪些文件转换失败了、为什么
```

**它会怎么做**：根据你的电脑上有什么软件选择办法。比如电脑上装了 Word 或 WPS、LibreOffice，可以用它们转换；没有的话，它会提议安装开源的转换工具。macOS 自带一些文档转换能力，它可能会直接用。

**要注意**：复杂排版（表格、文本框、批注）转换后可能走样，转完打开几份看看。

## 从一堆文档里提取信息做成表

这是最省时间的用法之一：几十份合同、简历、报告，每份里找几个关键信息，整理成一张表。

```text
这个文件夹里有 40 份供应商合同（PDF 和 Word 都有）。
请逐份阅读，提取下面这些信息，整理成「合同台账.xlsx」：
供应商名称 | 合同编号 | 签订日期 | 到期日期 | 合同金额 | 付款方式 | 自动续约条款（有/无，有的话摘录原文）| 文件名

要求：
- 找不到的信息填「未找到」，不要猜
- 到期日期在 90 天内的，在最后一列标「即将到期」
- 先做 3 份给我看格式，我确认后再做全部
- 做完告诉我哪几份内容读取有问题
```

同样的方法可以用在：

- **简历筛选**：「提取姓名（用编号代替）、学历、工作年限、核心技能、和岗位要求的匹配度」
- **调研报告**：「每份报告提取：研究对象、主要结论、关键数据，汇总成一张表」
- **会议纪要归档**：「提取每次会议的日期、待办事项和负责人，汇总所有未完成的待办」

::: danger 文档内容会发给模型
Codex 要读懂文档，就会把文档内容发给模型处理。合同、简历这类含个人信息和商业信息的文件，先确认公司规定允许；简历里的姓名、电话可以让它在表格里用编号代替。
:::

## 合并几十个 Excel

```text
这个文件夹里有 12 个月的销售表（1月.xlsx 到 12月.xlsx），每个表里有「明细」和「汇总」两个工作表。
请帮我：
1. 先打开几个看看，告诉我每个月的「明细」表头是否一致，不一致的地方列出来
2. 把 12 个月的「明细」合并成一张「全年明细.xlsx」，加一列「月份」
3. 合并后按「销售员」和「月份」做一张汇总表，放在第二个工作表
4. 告诉我合并前各表的行数之和、合并后的行数，两者应该一致
```

**它会做什么**：写一个 Python 小程序读所有表格、合并、汇总，然后运行。可能需要联网安装 pandas、openpyxl 这类表格工具库，弹窗时批准即可。

**要注意**：让它核对行数和合计金额，自己再随机抽几行和原表对一对。更多表格用法见 [财务与数据](/scenes/data)。

## 批量处理图片

```text
这个文件夹里是活动现场拍的 300 张照片（每张 5–10MB）。
请帮我：
1. 全部压缩到长边 1920 像素、每张 1MB 以内，放到「压缩版」文件夹
2. 按拍摄时间排序，重命名为「活动_001.jpg」「活动_002.jpg」……
3. 找出明显模糊或者几乎一样的连拍照片，列出清单给我挑（不要删）
先处理 5 张给我看效果。
```

更多图片处理（加水印、统一白底、按对照表重命名）的例子见 [小老板与个体户](/scenes/business#用-codex-处理一堆文件)。

## 让成果可以重复用

同样的活下个月还要做？让它把程序留下来：

```text
刚才的处理很好。请把这个处理过程整理成一个可以重复使用的小工具：
- 放在「工具」文件夹里
- 写一个「使用说明.txt」，告诉我下次怎么用（用最简单的话）
- 下次我只要把新文件放进「待处理」文件夹，运行一下就能得到同样的结果
```

怎么把它做成双击就能运行的小工具，或者设成每天自动运行，见 [定时任务和一键小工具](/scenes/automation-schedule)。

## 出问题了怎么办

| 情况 | 处理 |
|---|---|
| 它说做完了，但结果不对 | 具体告诉它哪里不对：「第 5 个文件的金额应该是 268，你写成了 26.8」 |
| 弹窗请求安装一个你不认识的东西 | 拒绝，问它「这是什么，为什么需要它，有没有不用安装的办法」 |
| 它处理到一半卡住了 | 桌面应用里点停止，命令行里按 `Esc` 打断，然后告诉它从哪里继续 |
| 文件被改坏了 | 这就是为什么要在副本上操作：删掉副本，重新复制一份再来 |
