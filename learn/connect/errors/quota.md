# 余额不足、额度已用完

**先看报错说的是哪一种「额度」：** 账户余额不足就 [充值](https://hivegpt.cn/purchase)；订阅的今日 / 本周 / 本月额度用完，等报错里写的重置时间，或充值后同一个 Key 自动改用余额继续；「API key 额度已用完」是你自己给这个 Key 设的上限到了，在 [API 密钥](https://hivegpt.cn/keys) 页调高或取消上限即可。

> 更新于 2026-10。这几种报错的请求都不扣费。

## 按报错内容判断

| 报错（`code`） | 状态码 | 原因 | 处理 |
|---|---|---|---|
| 「账户余额不足（当前余额 …）」（`INSUFFICIENT_BALANCE`） | 403 | 按量计费的余额用完了 | [充值](https://hivegpt.cn/purchase)，或改用订阅 |
| 「订阅今日 / 本周 / 本月额度已用完（已用 $… / 额度 $…），将于 … 重置」（`SUBSCRIPTION_INVALID`） | 403 | 套餐在这个时间段的额度用完了 | 等到报错里写的重置时间；或充值，同一个 Key 会自动改用余额 |
| 「订阅已于 … 到期」 | 403 | 套餐到期 | [续费](https://hivegpt.cn/purchase)，或充值后按量使用 |
| 「这个 Key 属于订阅分组，但你没有该分组的有效订阅」（`SUBSCRIPTION_NOT_FOUND`） | 403 | 没买这个分组的套餐，余额也不够 | 购买套餐，或充值后这个 Key 自动按量计费 |
| 「API key 额度已用完」（`API_KEY_QUOTA_EXHAUSTED` / `insufficient_quota`） | 429 | 这个 Key 设置的额度上限用完了 | 在「API 密钥」页调高或取消这个 Key 的额度上限 |

## 订阅和余额怎么自动切换

买了订阅后，同一个 Key 会**先用订阅额度**；订阅额度用完或到期后，**自动改用账户余额**继续，不用为订阅和按量各建一个 Key。所以：

- 订阅额度用完、余额也是 0：会看到额度用完的报错，充值后马上就能继续。
- 订阅额度用完、余额还有钱：不会报错，接下来的请求从余额扣。

两种方式怎么选，看 [价格页](https://hivegpt.cn/pricing) 的额度对比和按用量估算。

## Key 额度上限用完

在 [API 密钥](https://hivegpt.cn/keys) 页创建或编辑 Key 时，可以给它设一个额度上限（比如给沉浸式翻译单独一个 Key，最多花 $5）。到上限后这个 Key 返回 429 和「API key 额度已用完」，其他 Key 不受影响。

处理：编辑这个 Key，调高或取消额度上限。账户余额充足时，这个报错和余额无关，充值也不会解除。

## 怎么看钱花在哪了

- [使用记录](https://hivegpt.cn/usage)：每次请求的模型、token 数和扣费。
- 控制台首页：当前余额、订阅剩余额度和重置时间。

用量比预期高时，常见原因是对话上下文太长（每次请求都会带上之前的全部对话），开一个新对话就能降下来；或者某个工具在后台频繁请求（如整页翻译）。

其他报错看 [报错速查](/connect/errors/)。
