# 模型不存在、分组不支持模型

**这个报错说明地址和 Key 都没问题，只是模型名不对。** 每个分组能用的模型不同：用你的 Key 请求 `https://hivegpt.cn/v1/models` 看可用的模型名，把工具里的模型换成列表里的一个（注意大小写和横杠）；需要的模型不在列表里，就换一个支持它的分组的 Key。

> 更新于 2026-10。这类报错的请求不扣费。

## 你可能看到的报错

| 报错 | 状态码 | 意思 |
|---|---|---|
| 「当前 Key 所属分组「…」不支持模型 "…"，请在客户端换成该分组支持的模型，或换一个支持该模型的 Key」 | 404 | 这个分组没有这个模型 |
| 「…暂时没有可处理模型 … 请求的上游账号：可能是账号繁忙，也可能是这个 Key 的分组不支持所选模型」 | 503 | 账号繁忙或模型不支持，两种都有可能 |
| `model_not_found`、「The model … does not exist」 | 404 | 模型名不存在或拼错了 |

## 第一步：查你的 Key 能用哪些模型

```bash
curl https://hivegpt.cn/v1/models \
  -H "Authorization: Bearer sk-你的Key"
```

返回的 `data[].id` 就是可以填进工具里的模型名。不同分组返回的列表不一样，用你实际在用的那个 Key 查。

在 Cherry Studio、Chatbox 里也可以直接点「获取模型列表」，效果一样。

## 第二步：检查模型名

常见的写错方式：

- **拼写或格式不一致**：例如把 `gpt-5.5` 写成 `GPT-5.5`、`gpt5.5`、`gpt-5_5`。以 `/v1/models` 的返回为准，一个字符都不能差。
- **带了前缀**：有的工具会自动加 `openai/` 之类的前缀，在工具里改成不带前缀的模型名。
- **用了旧模型名**：工具的默认模型可能是很久以前的名字，换成列表里的新模型。
- **前后有空格**：手动输入时检查一下。

## 第三步：换一个分组的 Key

模型名没错但还是不支持，说明你的 Key 的分组里没有这个模型：

1. 到 [API 密钥](https://hivegpt.cn/keys?action=create) 页新建一个 Key，选包含这个模型的分组（创建时能看到每个分组的说明）。
2. 一个账号可以建多个 Key，分别用不同的分组，不用删旧的。
3. 买了订阅的话，订阅分组的 Key 会先用订阅额度。

选错分组是「模型不可用」最常见的原因。Codex 要用 GPT 类分组的 Key，见 [Codex 接入 HiveGPT](/codex/hivegpt)。

## 503「暂时没有可处理…的上游账号」

这个报错有两种可能：

- **账号繁忙**：过一会儿重试就好，见 [429 报错](/connect/errors/429)。
- **模型不支持**：重试也一直报，就按上面的三步检查模型名和分组。

分不清时，先换成 `/v1/models` 列表里的另一个模型试一下：能用，就是原来那个模型的问题。

其他报错看 [报错速查](/connect/errors/)。
