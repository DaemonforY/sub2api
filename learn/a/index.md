# A · AI 应用开发入门

## 这条路线讲什么

很多教程停在「调通一个 API」。真做项目时，马上会遇到：回答要边生成边显示、要记住上下文、要稳定输出 JSON 给程序用、要让模型去查数据库或调接口。这条路线按做一个真实应用的顺序讲：

1. **调通**：拿到 Key，用 curl / Python / JavaScript 发出第一个请求，看懂返回。
2. **对话**：流式输出和多轮对话，理解 messages 和上下文成本。
3. **结构化**：用 JSON Schema 让模型返回程序能直接用的数据。
4. **工具**：Function Calling，让模型决定什么时候调用你的函数。
5. **RAG**：用 Embedding 检索你自己的资料，让模型只根据资料回答。
6. **Agent**：把工具调用放进循环，让模型一步步完成任务。
7. **MCP**：把工具做成标准插件，接进编程助手等应用。
8. **上线**：成本、限流、错误重试，最后做一个网页聊天机器人作为结业项目。

每节课的代码都可以复制到本地运行；页面里的「动手试试」用 HiveGPT 的接口直接运行：登录后选一个你自己的 Key，按实际用量计费。

## 结业

满足下面的条件，可以在本页领取这条路线的结业证书：

- 学完 8 课；
- 各课测验总正确率 ≥ 80%；
- 完成检查点：在「API 密钥」页创建一个 Key，并用自己的 Key 成功调用一次 API（A1 里有这两个检查点）；
- 结业项目：A8 的网页聊天机器人（或你用这些知识做的其他应用），提交你在「我的网站」发布的网站，或 GitHub / Gitee 等平台上的公开链接。
