绘本是很多人最早看的「画」。它和普通插画最大的不同是：**它在讲故事**，一页一页翻过去，每一页都是故事里的一个瞬间，旁边还要放文字。

用 AI，你也能给家里的小朋友、给朋友，甚至给自己做一本小绘本。

| 画法 | 感觉 | 适合的故事 |
|---|---|---|
| **水彩** | 温柔、透气、梦幻 | 睡前故事、自然、季节 |
| **蜡笔** | 天真、热闹、像小朋友画的 | 低龄绘本、搞笑故事 |
| **剪纸拼贴** | 有趣、有层次、手工感强 | 动物、寓言、认知类绘本 |
| **水粉平涂** | 复古、雅致、有设计感 | 民间故事、城市故事、大一点的读者 |

绘本最怕「太像电脑画的」。这些画法的共同点是**看得出手作的痕迹**：纸纹、笔触、不完美的边。

## 一张图讲出「之前和之后」

最好看的绘本插画，不只画「现在」，还让你猜到**刚刚发生了什么**，或者**接下来会怎样**：

<CompareGrid
  :cols="1"
  items='[{"src":"/art-lab/j10-hint.webp","label":"猜猜刚才发生了什么？","change":"打翻的牛奶杯，一串小猫脚印从牛奶通到门口，门缝外一条正在溜走的尾巴"}]'
/>

画面里一只猫都没有完整出现，但你已经知道了整个故事。让一张图讲故事的办法：

- **留线索**：脚印、打翻的东西、半开的门、地上的信；
- **抓「快要发生」的瞬间**：伸出脚踩冰面之前、打开礼物之前、两个角色快要撞上之前；
- **角色的视线**：主角在看哪里，读者就会跟着看哪里；
- **夸张的表情和动作**：绘本读者常常很小，情绪要一眼看懂。

## 几页连起来：一本迷你绘本

一本绘本要几页连着讲。三页就能讲一个完整的小故事：**出发 → 遇到困难 → 解决**：

<CompareGrid
  :cols="3"
  items='[{"src":"/art-lab/j10-p1.webp","label":"第 1 页：出发","change":"小狐狸从树洞的家里探出头，提着灯笼，要去找朋友小熊"},{"src":"/art-lab/j10-p2.webp","label":"第 2 页：困难","change":"走到结冰的小河边，冰面上有一道裂纹，它犹豫地伸出一只脚"},{"src":"/art-lab/j10-p3.webp","label":"第 3 页：团聚","change":"温暖的山洞里，小狐狸和小熊挤在一起烤火，洞外还在下雪"}]'
/>

让几页连起来的三个办法：

1. **主角外形写成固定一段**，每一页原样复制：「一只小狐狸（橘红色的毛，白色的尾巴尖，围着一条红色的围巾）」（和 [J1 OC](/j/j1)、[J5 表情包](/j/j5) 同一招）。
2. **画法和配色也固定**，每页开头一样的「【画风】」那一句。
3. **页和页之间换景别**：大场景的页（交代世界）和特写的页（交代情绪）交替着来（[J7 漫画分镜](/j/j7) 讲过景别）。

::: tip 记得给字留地方
每一页都写上「画面上方 / 下方留出一片空白，用来放文字」。故事文字画好后自己加，AI 写字容易出错（[J9 海报](/j/j9) 讲过）。
:::

## 小读者喜欢什么

- **圆润的造型**、**温暖的颜色**；
- **简单的背景**，主角一眼就能找到；
- **藏一个小彩蛋**：每页角落里藏一只小老鼠、一只瓢虫，让小朋友去找；
- **重复**：同样的句子、同样的动作每页出现一次，小朋友会跟着念。

## 绘本页配方卡

```text
【画风】{水彩 / 蜡笔 / 剪纸拼贴 / 水粉平涂}绘本插画，{这种画法的特征}。
画面内容：绘本的一页：{固定的主角外形描述}{正在做什么：故事里最有意思的那个瞬间}；
{之前或之后的线索}；{场景和天气}。
画面{上方 / 下方}留出一片空白，用来放文字。画面里不要出现任何文字。
```

## 这节课记住三句话

- 绘本要**看得出手作**：水彩、蜡笔、剪纸拼贴、水粉平涂。
- 一张图讲故事：抓**最有意思的瞬间**，留下**之前或之后的线索**。
- 几页连起来：**固定主角外形和画法**，换景别，给字**留地方**。
