画自家的猫狗、幻想里的小精灵、像山一样大的神兽……动物大概是最让人开心的题材。这节课教你两件事：**怎么画萌**，以及**怎么造一只世界上没有的生物**。

## 「萌」是有公式的

<CompareGrid
  :cols="2"
  base="一只柴犬坐在草地上。{}"
  items='[{"src":"/art-lab/j4-plain.webp","label":"写实：好看，但不「萌」","change":"写实的动物摄影，侧面，自然光"},{"src":"/art-lab/j4-cute.webp","label":"萌化：忍不住想摸","change":"头很大、脸圆圆的，眼睛又大又圆、位置偏低，腿短短的，身体像个团子"}]'
/>

右边那只为什么萌？因为它被画成了**幼崽的样子**。人看到幼崽的特征，天生就会觉得可爱：

| 萌的特征 | 怎么写 |
|---|---|
| 头大、身体小 | 头很大，身体小小的 |
| 眼睛大、位置偏低 | 眼睛又大又圆，位置偏低 |
| 圆脸、圆身体 | 脸圆圆的，身体胖乎乎像个团子 |
| 四肢短 | 四条腿短短的 |
| 小动作 | 歪着头、伸懒腰、抱着东西、团成一团 |

这和 [J5 Q 版头像](/j/j5) 的道理一样：**越像幼崽，越萌**。

## 画你家的那只：写出专属特征

「一只橘猫」能画出一万只橘猫。要画出**你家那只**，得写出只有它才有的东西：

<CompareGrid
  :cols="1"
  items='[{"src":"/art-lab/j4-pet.webp","label":"不是「一只橘猫」，是「这只橘猫」","change":"橘白相间，左耳尖缺了一个小口，四只白袜子，白色尾巴尖，趴在窗台上眯眼晒太阳"}]'
/>

宠物描述清单：

1. **品种和毛色花纹**：橘白相间、三花、黑色带白围兜、奶油色卷毛……
2. **一两个专属特征**：缺口的耳朵、白袜子、歪歪的胡子、一只蓝眼一只黄眼、总是吐着舌头。
3. **它最常做的事**：晒太阳、盯着窗外的鸟、钻纸箱、把东西推下桌。
4. **它常待的地方**：窗台、沙发角、门口的鞋上。

::: tip 用照片当参考图
在 [无限画布](https://canvas.hivegpt.cn) 里上传你家宠物的照片当参考图，再写「画成治愈系绘本插画」，会更像它（[B3 参考图和图生图](/b/b3)）。
:::

## 奇幻生物：现实动物 + 混搭 + 元素

世界上没有的生物，其实都是**熟悉的东西重新组合**。公式：

> **一种现实动物** + **另一种动物或植物的特征** + **一种自然元素**（火、水、花、云、星空、光）

<CompareGrid
  :cols="2"
  items='[{"src":"/art-lab/j4-fox.webp","label":"狐狸 + 火焰","change":"尾巴是一团跳动的火焰，照亮了雪地"},{"src":"/art-lab/j4-deer.webp","label":"鹿 + 开花的树枝","change":"鹿角是长满新叶、开着小花的树枝，小鸟停在上面"},{"src":"/art-lab/j4-whale.webp","label":"鲸鱼 + 云和森林","change":"在黄昏的云海里游，身上长着青苔和小树"},{"src":"/art-lab/j4-moth.webp","label":"小猫 + 月光蛾翅膀","change":"背上长着淡绿色蛾翅，停在发光的蘑菇上"}]'
/>

有**熟悉的部分**（看得出是狐狸、是鹿），观众才看得懂；有**新奇的部分**（火焰尾巴、开花的鹿角），才让人记住。混搭别超过两三样，不然就成了「什么都像、什么都不是」的怪物。

### 再加一点设定

想让它更像一个「活着的生物」，问自己三个问题，然后**把答案画出来**：

- 它**住在哪**？雪原、森林深处、云上……
- 它**吃什么、做什么**？闻花、晒月光、收集亮晶晶的东西……
- 它**性格**怎样？胆小、好奇、慵懒……

火焰狐狸在雪地里低头闻花，比一只站着不动的火焰狐狸有意思得多。

## 配方卡

```text
萌宠：
【画风】治愈系绘本插画，水彩和彩铅质感，颜色温暖柔和。
画面内容：一只{品种和毛色花纹}，{一两个专属特征}，
{头大脸圆、眼睛大、腿短短的，胖乎乎}，正在{它最常做的事}，在{它常待的地方}。

奇幻生物：
【画风】奇幻生物图鉴插画，细腻的数字绘画，温暖的光影。
画面内容：一只{现实动物}，{混搭特征：尾巴是火焰 / 鹿角是开花的树枝 / 背上长着蛾翅}，
正在{它的栖息地}{做一件小事}，{旁边放一个衬出大小的东西}。
```

::: warning 原创，不要照搬
不要用现成游戏、动画里的生物名字（那些都有版权），用「现实动物 + 混搭」的公式设计一只你自己的。
:::

## 这节课记住三句话

- 萌 = **幼崽的特征**：头大、眼睛大而偏低、脸圆、腿短、胖乎乎。
- 画你家的那只：写出**专属特征**和它最常做的事。
- 奇幻生物 = **现实动物 + 混搭特征 + 自然元素**，再用大小对比和一件小事讲故事。
