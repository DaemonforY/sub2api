仙侠游戏里御剑飞过云海，江南雨夜的乌篷船和红灯笼，课本里一句「大漠孤烟直」……国风是很多人最想画、也最容易画「土」的题材。

画土的原因通常只有一个：**只写了「中国风」三个字**，模型就给你一锅大杂烩：宫殿、灯笼、龙、旗袍全堆在一起，朝代也乱成一团。这节课教你画得**地道又有意境**。

| 画法 | 感觉 | 适合 |
|---|---|---|
| **水墨写意** | 洒脱、空灵、有意境 | 山水、诗画、隐士、仙侠的远景 |
| **工笔** | 精致、清雅、细腻 | 人物、花鸟、古镇细节、诗画 |
| **青绿山水** | 富丽、壮阔、典雅 | 大场面的山河、仙境（北宋《千里江山图》就是青绿山水） |
| **国潮** | 潮流、热闹、年轻 | 海报、头像、节日、文创周边 |

## 中国传统色：比「红色」「蓝色」好看得多

国风的颜色，用**传统色的名字**写，模型会画得更雅致：

| 色名 | 大概是 | 适合 |
|---|---|---|
| 月白 | 带一点蓝的白 | 衣服、月光、天空 |
| 黛蓝 | 深沉的蓝灰 | 瓦片、远山、夜色 |
| 胭脂 | 深而柔的红 | 花、唇、点缀 |
| 朱砂 / 朱红 | 鲜亮的正红 | 灯笼、印章、宫墙、国潮 |
| 石青 / 石绿 | 浓艳的蓝和绿 | 青绿山水的山石 |
| 赭石 | 红褐色 | 山石、土地、树干 |
| 鹅黄 | 嫩嫩的浅黄 | 春天、花蕊、衣服 |
| 藕荷 | 浅浅的灰紫 | 衣服、黄昏、温柔的画面 |

一张图挑**两三种**就够了。比如古镇：黛蓝的瓦、月白的墙、一点朱红的灯笼。（配色的主次规矩在 [I4 配色](/i/i4) 里讲过。）

## 留白：空着的地方也是画

国画最特别的地方，是**敢于空着**。一大片空白可以是天、是水、是雾，让画面有呼吸感，也给看的人留了想象的空间。

在提示词里写「**画面上方留出大片空白**」「**大片留白**」，再把主体放在一角，国风的味道马上就出来了。塞得满满当当，反而不像国画。

## 诗画：把一句诗拆成画面

模型读不懂诗的「意思」，但能画出诗里的**东西**。所以要先拆：

| 拆什么 | 「大漠孤烟直，长河落日圆」 |
|---|---|
| **景物** | 沙漠、一缕烽烟、长河、落日、（一个骑马的人） |
| **样子** | 烟是笔直的，落日又大又圆 |
| **时间和天气** | 黄昏，无风 |
| **情绪** | 辽阔、苍茫、一点孤独 |

然后一样样写进提示词，再选画法和留白。诗句原文可以写进去当参考，但要加一句「画面里不要出现文字」：AI 写书法很容易写错字，题字最好自己后加。

::: tip 找诗、看诗画
- 不知道画哪首？去 [HiveGPT 诗词库](https://hivegpt.cn/poems) 按关键词或画面找诗。
- 想看一首诗怎么变成一组画：看看《使至塞上》的 [互动诗画](https://hivegpt.cn/shihua-play/shi-zhi-saishang/)。
:::

## 配方卡

```text
【画风】{中国水墨写意画 / 工笔淡彩画 / 青绿山水画 / 现代国潮插画}，
用{月白、黛蓝和一点朱红}几种传统色。
画面内容：{仙侠 / 古镇 / 一句诗的意境「……」}：{具体的景物、建筑、服饰和器物}，
{时间和天气}，{一个人物在做什么，可以很小}。画面{上方}留出大片空白。
画面里不要出现文字。
```

::: warning 三个常见翻车
- **只写「中国风」「古风」**：元素会乱堆。写具体的东西：白墙黛瓦、乌篷船、宽袖长袍。
- **朝代乱混**：汉服、旗袍、宫殿、现代路灯同框。不确定朝代的话，就别写太多服饰细节，多写景物。
- **让 AI 写书法题字**：常常写错，题字自己后加。
:::

## 这节课记住三句话

- 国风要**写具体**：白墙黛瓦、乌篷船、宽袖长袍，而不是「中国风」三个字。
- 四种画法：**水墨写意、工笔、青绿山水、国潮**；配色用两三种**传统色**，再**留白**。
- 画诗先**拆**：景物、样子、时间天气、情绪；字不要让 AI 写。
