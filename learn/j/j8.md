看动画的时候，你一定有过半夜被一碗面、一块煎蛋「馋哭」的经历。动画里的饭不一定画得多写实，但就是**特别好吃**。

这节课拆开这种「好吃」，再顺便学画**治愈系的小角落**：热可可、书桌、猫和窗外的雨。

## 让食物好吃的四招

| 招数 | 为什么 | 怎么写 |
|---|---|---|
| **高光和油光** | 亮晶晶 = 新鲜、多汁、刚出锅 | 汤面和蛋黄闪着油亮的高光，酱汁反光 |
| **热气** | 热气 = 刚做好、正冒着香味 | 白色的热气袅袅升起 |
| **暖光** | 暖黄的光让食物颜色更诱人 | 温暖的侧逆光、小店暖黄的灯光 |
| **正在吃的瞬间** | 动作让人代入「我也要吃」 | 筷子夹起面条、掰开流心、芝士拉丝、倒上酱汁 |

再加两个小技巧：

- **特写 + 浅景深**：食物占满画面，背景虚化成光斑（[I6 镜头](/i/i6)）。
- **一点绿色**：葱花、生菜、香草，暖色里一点绿，颜色马上活起来（[I4 配色](/i/i4) 的点缀色）。

::: tip 质感词
食物的质感写具体，会更香：外皮**焦脆**、蛋黄**流心**、芝士**拉丝**、蛋皮**蓬松**、米粒**晶莹**、汤汁**浓稠**、肉排**多汁**。[I7 质感](/i/i7) 讲过「质感是光画出来的」，食物也一样：油光就是光。
:::

## 治愈系小物：一个安静的角落

治愈系插画画的往往不是大场面，而是**生活里的一个小角落**：

<CompareGrid
  :cols="1"
  items='[{"src":"/art-lab/j8-cozy.webp","label":"下雨天的书桌一角","change":"冒着热气的热可可、翻开的书、小盆栽、趴着睡觉的橘猫，窗上挂着雨珠"}]'
/>

治愈感的配方：

- **几样有生活感的小物**：热饮、书、绿植、毛毯、台灯、猫……三五样就够，别塞满；
- **柔和的光**：阴天的窗光、清晨的阳光、台灯，不要强烈的对比；
- **低饱和的暖色**：奶油色、浅木色、淡绿，偶尔一点暖橙；
- **一点天气**：窗外的雨、雪、黄昏，让角落显得更温暖；
- **一点动静**：热气、睡着的猫、翻开的书页，像时间停了一下。

### 配方卡

```text
美食：
【画风】{日系动画插画 / 水彩手账 / 3D 微缩模型 / 写实美食摄影}。

{正在吃的动作：筷子夹起 / 掰开 / 倒酱}，白色的热气升起；背景虚化。

治愈小角落：
【画风】治愈系插画，柔和的水彩和彩铅质感，低饱和的暖色。
画面内容：{天气}的{窗边 / 书桌 / 床头}一角：{三五样小物}，{一只猫或一点动静}，{柔和的光}。
```

## 这节课记住三句话

- 好吃四招：**高光油光、热气、暖光、正在吃的瞬间**，再加一点绿。
- 四种画法：**动画作画、水彩手账、3D 微缩、写实摄影**，按用途选。
- 治愈角落：**三五样生活小物 + 柔和的光 + 低饱和暖色 + 一点天气和动静**。
