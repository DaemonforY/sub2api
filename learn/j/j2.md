打开一个新游戏，最先看到的往往是一张**大场景图**：远处有一座发光的塔、一座浮空的城、一扇巨大的门……你还没开始玩，就已经想冲过去看看了。

游戏公司在做游戏之前，会先画很多这样的图，叫**概念图**（concept art）：用来定下这个世界长什么样、是什么气氛。这节课教你画一张。

## 概念图要回答三个问题

### 1. 这是哪？给世界一个「奇怪的设定」

普通的森林、普通的城市，看过就忘。给它加一个**现实里没有的设定**，世界观就出来了：

- 森林 → **长在巨龟背上**的森林
- 图书馆 → **建在古树树洞里**的图书馆
- 城市 → **被植物吞没**的城市、**漂在云上**的城市、**永远在下雨**的城市

公式很简单：**普通地方 + 一个奇怪的设定**。

### 2. 往哪走？地标和引导

- **地标**：画面里最显眼、最想去的东西：一座塔、一棵巨树、一扇发光的门、一座火山。只放一个。
- **引导**：用**路、河、桥、光柱**把视线引到地标。[I5 构图](/i/i5) 里讲的引导线，在游戏图里就是「给玩家指路」。
- **最亮的地方给地标**：光在哪，眼睛就去哪。

### 3. 有多大？放一个小小的人

巨树到底有多巨？没有参照就看不出来。在近处或路上放一个**小小的角色**（最好是背影，像玩家自己），世界的尺度一下就出来了。再加上前景（近处的岩石、树枝）、中景（路）、远景（地标），画面就有了纵深。

::: tip 视角决定游戏类型
同一个森林，**正侧面**看是平台跳跃，**斜 45 度俯视**看是模拟经营，**从角色背后看**是动作冒险，**从高空俯瞰**是策略游戏。写提示词时把视角写进去，「游戏感」会强很多。
:::

## 概念图配方卡

```text
【画风】{游戏类型}游戏的概念图，{厚涂数字绘画 / 电影感数字绘画 / 水墨和厚涂结合}，{光影壮丽}。
画面内容：{普通地方 + 一个奇怪的设定}。
地标：远处{一座发光的塔 / 一扇巨大的门 / 一棵巨树}，是画面里最亮的地方。
引导：一条{路 / 河 / 栈道 / 光柱}从近处通向地标。
尺度：{近处 / 路上}有一个小小的{冒险者背影}，衬出世界的巨大。
```

::: warning 别画成「游戏截图」
如果不想要血条、按钮、地图这些界面，记得写「没有任何游戏界面和文字」。也不要写现成游戏的名字，用上面的特征描述就好。
:::

## 这节课记住三句话

- 概念图回答三个问题：**这是哪**（普通地方 + 奇怪设定）、**往哪走**（地标 + 引导）、**有多大**（小小的人）。
- 只放一个地标，让它**最亮**，用路、河、光柱把视线引过去。
- 写清**游戏类型和视角**，「游戏感」会强很多；记得写「没有任何游戏界面和文字」。
