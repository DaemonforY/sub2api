前面的课大多是动漫和游戏风格。这一课换个口味：**写实人像**，像摄影师拍出来的那种。

写实人像最常见的问题，是 AI 画出来的人**像塑料**：皮肤光滑得像打了蜡，五官完美对称，看一眼就知道是 AI。这节课教你画出「像真的一样」的人，也讲清楚什么能画、什么不能画。

真实的人都有**瑕疵**：毛孔、皱纹、雀斑、碎发、衣服的褶皱和起球。写实人像要做的，恰恰是把这些「不完美」写进去。

## 真实感清单

| 部位 | 写进提示词 |
|---|---|
| **皮肤** | 真实的皮肤纹理，看得见毛孔、细纹、雀斑或胡茬（**不要**写「完美无瑕」「光滑」） |
| **头发** | 几缕碎发、自然的发丝、被风吹乱 |
| **眼睛** | 眼睛里有窗户或灯的反光，视线有方向 |
| **衣服** | 布料的质感：毛衣起球、衬衫褶皱、围裙上的面粉 |
| **手** | 手上的皱纹、老茧、指甲，手在做一件事 |
| **镜头** | 85mm 或 50mm 镜头、浅景深、胶片颗粒 |

::: tip 镜头和胶片
写「**85mm 镜头，浅景深**」，背景会虚化，脸的比例也更自然（[I6 镜头](/i/i6)）；加一句「**胶片质感、细微的颗粒**」，会少很多数码的塑料感。
:::

/>

| 布光 | 感觉 | 适合 |
|---|---|---|
| **窗边侧光** | 自然、安静、真实 | 日常、纪实、温柔的人像 |
| **伦勃朗光** | 戏剧、深沉、古典 | 有故事的老人、艺术家、严肃的角色 |
| **逆光** | 温暖、怀旧、像回忆 | 黄昏、家人、青春 |
| **霓虹光** | 电影感、酷、都市 | 夜景、赛博朋克、音乐人 |

伦勃朗是 17 世纪的荷兰画家，最爱画这种「一侧亮、暗面脸颊有一块三角亮斑」的光，后来摄影师就用他的名字给这种布光命名。[I3 打光](/i/i3) 讲过光的方向，人像布光就是把它用在脸上。

## 环境人像：让一个人讲故事

只拍一张脸，看到的是「长什么样」；把人放进**他生活和工作的地方**，看到的是「他是谁」：

<CompareGrid
  :cols="2"
  items='[{"src":"/art-lab/j11-baker.webp","label":"清晨的面包师","change":"沾满面粉的围裙，从烤箱里拿出一盘刚烤好的面包，热气升起，周围是面粉袋和木头操作台"},{"src":"/art-lab/j11-fisher.webp","label":"海边的老渔民","change":"满脸风霜的皱纹，旧毛线帽，在船头整理渔网，手上有老茧，背后是起雾的海和灯塔"}]'
/>

环境人像的配方：

- **一个职业或身份**：面包师、渔民、修书人、修车师傅、花店老板；
- **一件正在做的事**：拿出面包、整理渔网、修补旧书；
- **几样会说话的道具**：沾面粉的围裙、手上的老茧、桌上的工具；
- **一个表情**：专注、微笑、望向远方。

## 能画什么，不能画什么

写实人像越像真的，越要注意边界：

::: warning 三条规矩
- **只画虚构的人**：不要生成真实的人，尤其是明星、公众人物和身边的同学朋友。很多平台也会直接拦截。
- **不用别人的照片**：拿别人的照片生成写实人像，会侵犯别人的**肖像权**。用自己的照片，也要想清楚会被怎么用。
- **不冒充真实照片**：AI 人像发出去时说明是 AI 生成，不要拿它当真实的照片去骗人，比如假的证件照、假新闻、假的「真人」账号。
:::

## 这节课记住三句话

- 写实要写**不完美**：毛孔、皱纹、碎发、衣服的褶皱；加上 85mm 浅景深和胶片质感。
- 四种人像布光：**窗边侧光、伦勃朗光、逆光、霓虹光**，按情绪选。
- 用**环境和道具**讲故事；只画**虚构的人**，不用别人的照片，不冒充真实照片。
