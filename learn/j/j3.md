宫崎骏和吉卜力电影里的田野、小镇和森林，新海诚电影里的蓝天、电车和雨后的路口……很多人喜欢动画，是从**喜欢里面的风景**开始的。随便暂停一帧，都能直接当壁纸。

这节课把这种「动画电影感」拆开：它们好看在哪，怎么用提示词写出来，**而且不用报任何导演或工作室的名字**。

## 两种动画电影感，拆开看

| | 手绘温暖派 | 光影唯美派 |
|---|---|---|
| 很多人会想到 | 宫崎骏、吉卜力的电影 | 新海诚的电影 |
| **天空** | 蓬松饱满的积雨云，柔和的蓝 | 通透到发光的蓝，粉紫色的晚霞，飞机云，星空 |
| **光** | 午后的暖阳，树荫下一块块光斑 | 逆光、镜头光晕、丁达尔光柱、积水和玻璃的反光 |
| **颜色** | 自然、温暖、不刺眼，绿色层次特别多 | 高饱和、清澈，冷暖对比强 |
| **笔触** | 水粉水彩手绘，看得见笔触 | 照片级精细，干净锐利 |
| **常见场景** | 田野、森林、海边小镇、老街、会飞的东西 | 城市路口、电车、便利店、天桥、天台、电线杆 |
| **生活痕迹** | 晾着的衣服、自行车、热腾腾的饭、风吹动的草 | 自动贩卖机的光、亮着的窗、红绿灯、雨伞 |
| **情绪** | 温柔、怀旧、自由（风一直在吹） | 思念、孤独、青春里一点点伤感 |

::: tip 为什么不直接写「吉卜力风」「新海诚风」？
提示词中心里这样写的提示词大约有 20 条，但只报名字的效果很不稳：模型理解不一样，有的平台还会拦截在世画师的名字。**把上面表格里的特征写出来**，你得到的就是「你想要的那种感觉」，而不是模型记忆里的平均版。这也是 [I8 画风图鉴](/i/i8) 的核心方法：画风 = 线条 + 颜色 + 光 + 质感。
:::

| 风景 | 一定要写的 | 加分的小东西 |
|---|---|---|
| **天空** | 时间（黄昏 / 清晨 / 夜晚）、颜色怎么渐变、云的样子 | 飞机云、电线杆剪影、第一颗星、彗星 |
| **森林** | 光从哪里漏下来、绿色的层次 | 光斑、青苔、石灯笼、林间小路、萤火 |
| **大海** | 近处和远处海水的颜色、透明度 | 沙底的光纹、防波堤、灯塔、海鸥、浪花 |
| **城市** | 时间和天气、光源（灯、招牌、窗） | 积水倒影、斑马线、自动贩卖机、电车、天桥 |

## 让风景有故事的四个小技巧

### 1. 天空当主角，人物小小的

<CompareGrid
  :cols="2"
  items='[{"src":"/art-lab/j3-big.webp","label":"人物占满画面：变成了人像","change":"撑伞女孩的上半身特写，背景是模糊的街道"},{"src":"/art-lab/j3-small.webp","label":"人物小小的：世界一下变大了","change":"女孩只是右下角一个小人影，天空占三分之二，晚霞染红了云"}]'
/>

动画电影里最让人难忘的风景镜头，人物往往**只有指甲盖那么大**。人越小，世界越大，观众越容易把自己代入进去。写「一个小小的人影」「画面角落」「远远的」就行，位置放在三分线附近（[I5 构图](/i/i5) 讲过）。

### 2. 加一点生活痕迹

空荡荡的风景只是「风景照」，加一件**有人生活过的东西**，就有了故事：晾着的衣服、靠在墙边的自行车、亮着灯的窗、门口的拖鞋、自动贩卖机、车筐里的西瓜。看的人会自己脑补：这里住着谁？刚刚发生了什么？

### 3. 选一个有情绪的时间

正午的阳光最平淡。动画电影最爱这几个时间：**夏日午后**（蝉鸣、积雨云）、**黄昏的魔幻时刻**（天空粉紫、一切都镶金边）、**雨后**（地面积水、云缝透光）、**雪夜**（安静、暖色的窗）。时间选对了，情绪就有了一半（[I3 打光](/i/i3) 里有每个时间的配方）。

### 4. 让画面动起来：风

静止的画面里加一点风：云在流动、草被吹倒一片、晾着的衣服和女孩的头发飘起来、花瓣和树叶在飞。手绘温暖派特别爱画风，它让画面有「呼吸」。

## 配方卡

把 `{}` 换成你的，挑一个画风那一句，直接用：

```text
【画风】{选一个，见下面}。
画面内容：{地点}，{时间和天气}。天空占画面三分之二，{天空的样子：积雨云 / 晚霞 / 飞机云 / 星空}。
光：{光从哪来，比如逆光、树叶缝里的光斑、积水的反光}。
生活痕迹：{晾着的衣服 / 自行车 / 亮灯的窗 / 自动贩卖机}；{一个小小的人影在做什么}，在画面{左下角 / 右下角}。
风：{云在流动 / 草被风吹倒 / 头发和衣服飘起来}。
```

画风那一句：

- **手绘温暖派**：像经典手绘动画电影的背景，水粉和水彩手绘，笔触看得见，云朵饱满蓬松，颜色自然温暖、不刺眼，怀旧又温柔。
- **光影唯美派**：照片级精细的动画电影背景，高饱和通透的天空，强烈的逆光和镜头光晕，地面和水面反光，色彩清澈，带一点淡淡的伤感。

::: details 彩蛋：动画里的风景是谁画的？
动画里的风景叫**背景美术**，是美术师单独画的一整幅画，人物再叠在上面（[K2](/k/k2) 讲了为什么要这样分开）。手绘年代的动画电影背景，很多是用广告颜料（水粉）一笔笔画出来的，所以有那种温暖的手绘味。

新海诚的电影里，很多场景都照着现实中的街道、车站和神社来画，再加上夸张的光效。于是粉丝们会专门去这些地方拍照打卡，这叫**圣地巡礼**。下次去旅行，也可以试试把自己拍的照片画成「动画电影的一帧」。
:::

## 这节课记住三句话

- 动画电影感有两派：**手绘温暖**（水彩笔触、积雨云、自然的绿）和**光影唯美**（通透天空、逆光、反光）。写特征，不报名字。
- 天空、森林、大海、城市，各有一定要写的东西：时间、光、颜色和那几样「加分小物」。
- **天空当主角、人物小小的、加一件生活痕迹、选一个有情绪的时间、加点风**，风景就有了故事。
