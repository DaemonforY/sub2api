## 1. 模型接入：火山方舟

### 1.1 套餐不能用的原因

- **Coding Plan**（Lite ¥40/月、Pro ¥200/月）：只含文本 / 代码模型（豆包 Seed、GLM、Kimi、DeepSeek 等），没有图片、视频、语音；官方说明只面向个人开发，「在非 AI 编程工具中使用可能被识别为滥用，导致订阅停用或封号」。
- **Agent Plan**（¥40 / 200 / 500 / 1000 每月，按 AFP 积分）：包含 Seedream 5.0 lite、Seedance 1.5 pro / 2.0 / 2.0 fast、豆包 TTS 2.0、ASR，但同样是个人套餐、只能在 AI 工具里用；最低档不含视频；图片约 99 积分 / 张（Small 档 ¥40 = 2 万积分，折合约 ¥0.2 / 张，与按量价格差不多），省不了多少钱。
- 结论：你自己在画布里试效果可以用 Agent Plan；**给网站用户用必须走按量付费 API**。

### 1.2 按量付费价格（2026-10 查询，下单前以官网为准）

| 能力 | 模型 | 参考成本 | 建议售价 |
|---|---|---|---|
| 图片 | Seedream 5.0 lite / pro | ¥0.22 / 张；¥0.30 起 / 张 | ¥0.35 / ¥0.50 每张 |
| 视频 | Seedance 2.0 mini（480P/720P，4–15 秒） | 约 ¥0.5 / 秒 | 按秒计费，约 ¥0.8 / 秒 |
| 视频 | Seedance 2.0 / 2.0 fast | 约 ¥1 / 秒；fast 约便宜 20% | 约 ¥1.5 / 秒 |
| 视频 | Seedance 2.5（720P / 1080P，最长 30 秒） | 约 ¥1.5 / 秒；1080P 约 ¥3.7 / 秒 | 高级档，按秒 |
| 语音 | 豆包语音合成 2.0（另一个产品「豆包语音」，单独开通） | ¥3 / 万字符；另有并发费 | ¥5 / 万字符 |

视频按「输出视频 token」计费：（输入 + 输出时长）× 宽 × 高 × 帧率 ÷ 1024，分辨率、比例、是否带参考视频都会影响价格，网关按上游返回的 token 用量结算，前端提前给出估价。

### 1.3 网关要做的事

| 能力 | 上游接口 | 网关对外 | 说明 |
|---|---|---|---|
| 图片 | 方舟 `/api/v3/images/generations`（接近 OpenAI 格式，参考图走 URL / base64） | 现有 `/v1/images/generations`、`/v1/images/edits` | 新增「火山方舟」平台账号类型；multipart 改图转成 JSON；按张计费 |
| 视频 | 方舟 `/api/v3/contents/generations/tasks`（异步任务） | 现有 `/v1/videos`、`/v1/videos/{id}`、`/content`（画布已在用，现在接的是 Grok） | 首帧 / 尾帧 / 参考图映射到 `content[]`；轮询转发；按 token 结算，复用 `video_billing` |
| 语音 | 豆包语音 HTTP 接口（appid + token，音色 voice_type） | `/v1/audio/speech` | 音色列表映射成 OpenAI 的 `voice`；按字符计费 |

合规：方舟的 Seedance 规则要求平台能把违规内容追溯到终端用户、有警告 / 下架 / 封禁流程并留存日志。我们已有按用户的请求日志，补「违规处理记录」即可。

**需要你准备**：火山引擎企业实名账号，开通 Seedream / Seedance、豆包语音，在后台「账号」里填入 API Key（由你填写，我不经手）。

## 2. 账号打通

### 2.1 现状

画布没有账号，作品存在浏览器里；「一键连接」弹窗只是把主站的 API Key 交给画布，用于生图计费、提示词收藏同步、图片工具、发布网页。用户在画布里看不到自己是谁、余额多少，也没有回主站的理由。

### 2.2 方案：HiveGPT 是唯一账号，画布用它登录

```
画布「登录 / 注册」 → 弹窗打开 hivegpt.cn/canvas-connect?state=…
  ├─ 未登录：在弹窗里登录或注册（注册完回到这一步，邀请码一路带着）
  └─ 已登录：确认授权「HiveGPT 画布」
        ↓
主站在 hivegpt.cn 写入 HttpOnly 会话 Cookie（仅用于画布接口，30 天，可吊销）
并像现在一样把 API Key 交给画布（首次自动建一个「无限画布」Key）
        ↓
画布以 credentials: include 调 hivegpt.cn/api/v1/canvas/*：我是谁、余额、订阅、作品、关注…
```

- **为什么用 Cookie 不用 Token**：canvas.hivegpt.cn 和 hivegpt.cn 是同站，浏览器会带上 hivegpt.cn 的 SameSite=Lax Cookie，Safari 也不拦；HttpOnly 让画布里的脚本（包括用户装的模型插件）拿不到登录凭证。托管网站在 xinduanju.top，是跨站，带不上这个 Cookie，这正是当初把网站托管放到别的域名的好处。
- **防 CSRF**：画布接口只接受 `Origin: https://canvas.hivegpt.cn`，并要求自定义请求头；CORS 只对这个来源开 `Allow-Credentials`。
- **权限范围**：这个会话只能用画布相关接口（资料、作品、关注、同步），不能改密码、不能支付、不能建删 Key。
- **管理**：主站「个人设置 → 已登录的设备」可以看到并退出画布会话；画布「退出登录」同时清掉 Cookie 和本地 Key。
- **兼容**：只填了 API Key、没登录的老用户照常能用，顶部提示「登录后可以发布作品、同步收藏」。

### 2.3 两站互相引流

| 方向 | 入口 |
|---|---|
| 画布 → 主站 | 顶部头像菜单（主页、作品、余额、订阅、充值）；余额不足时的「去充值」；发布作品后跳到主站作品页；活动、提示词库 |
| 主站 → 画布 | 作品页「在画布中做同款」（带提示词和参考图新建画布）；首页作品墙；个人中心「我的画布作品」；活动页「用画布参赛」 |
| 外部 → 两站 | 作品 / 主页 / 作品集的分享链接和海报二维码带**分享者**的邀请码（`?aff=`，已上线；作者分享自己的作品即作者得奖励），画布记住 30 天并带到所有去主站的链接，主站任意页面落地都会记下，注册时自动填入（复用现有邀请返利）；分享卡片有标题、封面（服务端给 `/w/:id`、`/u/:name` 注入 meta 标签） |

## 3. 创作社区

### 3.1 功能

| 功能 | MVP（S2） | 之后（S3） |
|---|---|---|
| 个人主页 | 用户名（3–20 位，唯一，规则同站点名）、昵称、头像、简介、链接；作品 / 作品集 / 喜欢 三个页签；关注数、粉丝数、获赞数 | 封面图、创作者数据 |
| 作品 | 1–9 张图；标题、描述、提示词（可选择隐藏）、模型和参数、来源（画布 / 工作台 / 工具箱 / 比赛）、场景标签（复用提示词库的场景）；公开 / 仅链接可见 / 私密 | 视频、音频、网页作品（托管网站截图做封面） |
| 作品集 | 自己的作品按主题分组、排序，可公开 | 合作作品集 |
| 收藏 | 收藏别人的作品（默认私密） | 收藏夹分组 |
| 关注 | 关注 / 取关，关注列表、粉丝列表，「关注」信息流 | 推荐关注 |
| 互动 | 点赞、收藏、分享（复制链接、生成海报）、做同款（计数） | **评论**（法规要求评论者实名，需要先做手机号验证，目前主站没有短信） |
| 发现页 | 推荐（点赞 / 收藏 / 做同款加权并随时间衰减，叠加后台「精选」）、最新、关注；按类型和场景筛选；瀑布流 | 个性化推荐 |
| 通知 | 新粉丝、被赞、被收藏、被做同款、被精选（站内铃铛，两站都显示） | 评论、@ 提及 |
| 比赛 | — | 比赛投稿直接选自己的作品 |

**隐私**：老用户不会被自动公开。第一次发布作品时才创建主页、起用户名。任何地方都不显示邮箱。

### 3.2 审核与合规

- **AI 标识**：《人工智能生成合成内容标识办法》（2025-09-01 起施行）要求传播平台标识 AI 生成内容。作品页和卡片一律显示「AI 生成」，上传的文件保留或补写隐式标识（元数据）。
- **先审后发 / 先发后审**：
  - 标题、描述、提示词、用户名、简介先过关键词检查。
  - 图片可选交给视觉模型复核，与网站托管共用「审核模型」设置。
  - 没有命中的直接公开，命中的进后台审核队列。
- **举报**：每个作品和主页都有举报入口，进后台举报队列（与网站举报同一套）。后台可以隐藏或精选作品、禁止某用户发布。
- **防刷**：
  - 新账号每天发布、关注、点赞都有上限。
  - 点赞、收藏按账号去重。
  - 计数在数据库事务里更新。
- **评论**：《互联网跟帖评论服务管理规定》要求后台实名，等有了手机号验证再开。

### 3.3 数据表（主站，原生 SQL，与网站托管同样写法）

```
user_profiles      user_id PK, handle UNIQUE, display_name, avatar_file, bio, links JSONB,
                   works_count, followers_count, following_count, likes_received, status, created_at
works              id, user_id, kind(image|video|audio|site), title, description, prompt, show_prompt,
                   model, params JSONB, source, tags TEXT[], visibility(public|unlisted|private),
                   status(pending|approved|rejected|hidden), featured_at, like_count, favorite_count,
                   remix_count, view_count, remix_of, created_at, updated_at
work_media         id, work_id, position, file, mime, width, height, bytes, thumb_file
collections        id, user_id, title, description, cover_work_id, visibility, works_count, …
collection_items   collection_id, work_id, position
follows            follower_id, followee_id, created_at  (PK 两列)
work_likes / work_favorites   work_id, user_id, created_at  (PK 两列)
notifications      id, user_id, kind, actor_id, work_id, read_at, created_at
work_reports       与 site_reports 同结构
```

- **图片存储**：先存服务器数据盘，上传时生成 480px / 1200px 的 WebP 缩略图。
- **配额**：普通用户 200 个作品，订阅用户 2000 个。
- **扩容**：流量起来后，和网站托管 P3 一起换成 COS / R2 加 CDN。

## 4. 页面样式

### 4.1 现在的问题（看了两站首页）

1. **两个品牌**：主站叫 HiveGPT，用青紫渐变；画布叫「无限画布」，只用紫色。用户感觉不到这是同一家。
2. **首页面向谁不清楚**：首屏是开发者终端（`curl /v1/messages`），下面又是画图输入框和创作卡片。要做创作社区，首屏应该先展示作品。
3. **画布顶栏**：右上角十几个没有文字的图标，新用户看不懂；没有账号入口。
4. **语言切换**：主站的语言切换用了国旗图标，建议改成「中 / EN」文字。

### 4.2 统一规范

| 项 | 规范 |
|---|---|
| 品牌 | 主品牌 HiveGPT；画布叫「HiveGPT 画布」（「无限画布」保留为功能说明）；两站左上角用同一个 logo，旁边是产品名 |
| 颜色 | 主色紫 `#7C3AED`（按钮、链接、选中态）；品牌渐变 青 `#2DD4BF` → 紫 `#8B5CF6` 只用在首屏标题和少数强调处；中性色 stone；成功 / 警告 / 错误沿用现有 |
| 圆角 / 阴影 | 卡片 12px、控件 8px、弹窗 16px；深色模式用描边代替阴影 |
| 字体 | 系统字体栈（PingFang SC / HarmonyOS Sans / Microsoft YaHei）；标题 600，正文 14px，辅助 12px |
| 主题 | 默认深色，支持浅色；作品图片区域永远用中性底色，不跟主题变 |
| 移动端 | 发现页、作品页、主页必须适配手机（分享主要从微信打开） |

### 4.3 导航

- 主站顶部：**发现 · 画布 · 工具 · 活动 · 提示词 · 开放平台**，右侧通知、头像。「开放平台」收纳 API 文档、价格、Key 管理，给开发者。
- 画布顶部：左边 logo 加画布名；右边「发现」「通知」「头像菜单」；现在的工具图标收进「更多」。
- 首页（未登录）：
  - 首屏写「用 AI 画图、做视频、做网页」，配输入框，下方直接是作品墙。
  - 再往下是三个入口卡片（画布、工具、活动）。
  - 开发者区放在最后，或单独放到 /developers。

### 4.4 关键页面布局

- **发现页**：顶部有「推荐 / 最新 / 关注」页签，加类型和场景筛选，下面是瀑布流卡片。卡片显示封面、标题、作者头像、点赞数和「AI 生成」角标。
- **作品页**：左边大图（多图可左右切换）。右边依次是：
  - 作者卡片和关注按钮；
  - 标题、描述；
  - 提示词卡片，带「复制」和「在画布中做同款」；
  - 模型参数、标签；
  - 点赞、收藏、分享、举报。

  下方是「作者的更多作品」和「相似作品」。
- **个人主页**：上方是头像、昵称、@用户名、简介、链接、三项数据和「关注 / 编辑资料」，下方是作品 / 作品集 / 喜欢三个页签。
- **画布「发布作品」弹窗**：
  - 可勾选多张节点图片，自动带上提示词、模型和参数；
  - 填标题、选作品集和可见范围，选择是否公开提示词；
  - 发布后给出作品链接和分享海报。
