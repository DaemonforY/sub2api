# 付费课程（C1、C2 已上线）

2026-10-04。后台上架付费课程，用户付款后在「我的课程」里拿到百度网盘链接和提取码。

## 0. 结论

- **放在主站**：
  - 页面：`hivegpt.cn/courses` 列表、课程详情页、「我的课程」，后台加「课程」菜单。
  - 账号、支付、退款、邀请都复用现有系统。
  - 免费的 [AI 学习](AI_LEARN_PLAN.md) 课时末尾推荐相关的付费课。
- **付款**：
  - 新增订单类型 `course`，走现有微信 / 支付宝通道。
  - 付款成功即开通（发货），退款自动收回。
  - 先不支持用余额买课，理由见 §4。
- **内容放哪**：
  - 正片放百度网盘（你的方案，零带宽成本）。
  - 课程介绍、配图存在主站：介绍是 Markdown 存数据库，图片和社区作品一样放服务器磁盘。
  - 试看视频放国内对象存储 + CDN。
  - 以后如果要站内加密播放正片，再上云点播。见 §3。
- **防外传**：
  - 网盘链接加密存储，只返回给已购用户，每次查看都记日志。
  - 链接外泄后，后台换新链接，已购用户自动看到新链接。
- **分期**：
  - C1 上架 + 购买 + 发货，4–5 天。
  - C2 试看视频、优惠、分销、兑换码，2–3 天。
  - C3 站内加密播放，按需。

## 1. 用户能做什么

| 页面 | 内容 |
|---|---|
| 课程列表 `/courses` | 分类筛选；卡片显示封面、标题、一句话卖点、课时数 / 总时长、价格（划线原价）、已购人数；已购的显示「已购买」 |
| 课程详情 `/courses/<slug>` | 封面 / 试看视频、标题、价格、「立即购买」；适合谁、学完能做什么；课程大纲（章节、时长，标「试看」的可直接看）；图文介绍；常见问题（怎么拿到课程、要不要网盘会员、能否退款） |
| 购买 | 弹窗确认价格和支付方式（复用充值的支付弹窗），勾选「虚拟商品，查看网盘链接后不支持退款」后支付 |
| 我的课程（用户中心） | 已购课程列表；每门课有「获取课程」卡片：网盘链接（一键复制、打开百度网盘）、提取码（一键复制）、解压密码（如有）、补充说明；显示「最近更新」，链接换过会提示 |
| 通知 | 付款成功、链接更新时站内提示 + 邮件。邮件里只放「去我的课程查看」的链接，不放网盘链接本身 |

## 2. 后台能做什么

- **课程管理**：
  - 新建 / 编辑：标题、slug、分类、封面、一句话卖点、价格、原价、介绍（Markdown 编辑器，可插图）、大纲（章节和时长，可标试看）、试看内容（视频或图文）、常见问题、排序。
  - 状态：草稿 / 上架 / 下架。下架后已购用户仍能查看。
- **发货信息**：
  - 网盘链接、提取码、解压密码、补充说明。
  - 每次修改都存一版历史，可选「通知已购用户」。
- **学员**：
  - 按课程查看购买记录：用户、订单、时间、首次查看链接时间、查看次数。
  - 手动开通（线下收款、赠送）和收回。
- **数据**：每门课的浏览、下单、付款、退款。
- **优惠**（C2）：
  - 学生 / 老师 edu.cn 认证价，复用现有认证。
  - 限时价。
  - 课程兑换码（批量生成，复用现有兑换码模块，给合作方或线下售卖）。
- **分销**（C2）：邀请人按比例拿返利（比例后台可设），复用现有邀请返利。

## 3. 视频、图文放哪里

| 放哪 | 放什么 | 成本 | 要注意 |
|---|---|---|---|
| **百度网盘** | 正片视频、课件、源码 | 用你现有的网盘会员，没有流量费 | 买家不开会员下载慢；链接可能被转发；分享内容可能被网盘审核屏蔽（要准备换链接）；没法给每个买家加水印 |
| **主站数据库 + 服务器磁盘**（首尔） | 课程介绍（Markdown）、封面和配图 | 已有，几乎为零 | 图片走现有的社区媒体方式即可；**不适合视频**：首尔到国内带宽小，看视频会卡 |
| **国内对象存储 + CDN**（阿里云 OSS 或腾讯云 COS） | 试看视频、宣传片、较大的图片 | 存储和 CDN 流量都按量计费，每 GB 几毛钱量级，以官网为准。5 分钟 720p 试看约 30 MB，播放 1000 次约 30 GB 流量 | 国内 CDN 要用**已备案的域名**。`xinduanju.top` 的学习站在阿里云国内服务器上，应该已经备案，可以用 `media.xinduanju.top` 这类子域名，需要你确认。存储桶设私有，主站发短期签名链接，防止被盗链 |
| **云点播**（阿里云 / 腾讯云视频点播，C3） | 将来如果正片改为站内播放 | 转码、存储、流量都按量计费 | 支持 HLS 加密、按用户加水印、防下载，是站内卖视频课的正规做法；开发量和成本都更高，等课程卖起来再上 |

**建议**：
- 第一期只用前两行：正片在网盘，介绍和图片在主站，试看先用图文。
- 第二期开通 OSS 放试看视频。
- 对象存储建议选**阿里云 OSS**。你的域名解析和学习站都在阿里云，备案和 CDN 配置在同一个账号里做最省事。

## 4. 为什么先不用余额买课

- 余额是 API 额度，里面有邀请返利、活动赠送。用来买课，会让「送的额度」变成现金等价物，返利规则要跟着改。
- 课程收入和 API 充值混在一起，对账、退款都不好算。
- 直接付款的订单本身就是课程收入记录，退款时直接原路退回并收回课程。

如果以后想支持，可以只允许「充值获得的余额」买课，单独记账。

## 5. 技术方案

- **订单**：
  - `payment_orders` 增加订单类型 `course` 和可空字段 `course_id`（Ent schema，`make generate`）。
  - 下单时按课程价格定金额（学生价、限时价在服务端计算），不接受前端传的金额。
  - 履约分支新增 `ExecuteCourseFulfillment`：写入开通记录，幂等。
  - 退款分支：收回开通记录。
- **数据表**（原生 SQL，和社区模块同样写法）：
  - `courses`（slug、标题、分类、封面、价格、原价、介绍、大纲 jsonb、试看内容、状态、排序、销量）。
  - `course_deliveries`（课程、版本、网盘链接 / 提取码 / 解压密码，用现有 AES 字段加密；说明；修改人；时间）。
  - `course_enrollments`（用户、课程、订单、来源：购买 / 后台开通 / 兑换码；状态：有效 / 已收回；首次查看时间），一人一课唯一。
  - `course_access_logs`（用户、课程、IP、时间），用来发现异常查看。
- **接口**：

| 接口 | 说明 |
|---|---|
| `GET /api/v1/courses`、`GET /api/v1/courses/:slug` | 公开：列表和详情（不含发货信息），带「已购」状态 |
| `POST /api/v1/payment/orders`（`order_type=course, course_id`） | 下单，复用现有支付 |
| `GET /api/v1/user/courses` | 我的课程 |
| `GET /api/v1/user/courses/:id/delivery` | 发货信息：只对有效开通的用户返回；记访问日志；限频（每人每课每分钟 10 次） |
| `/api/v1/admin/courses/*` | 课程增删改、上传封面 / 配图、发货信息和历史、学员列表、开通 / 收回、数据 |

- **防外传**：
  - 详情页、列表、订单接口都不返回链接。
  - 发货接口要求登录且已开通。
  - 链接加密存储。
  - 同一账号短时间内从很多不同 IP 查看时，在后台标记出来。
  - 网盘那边设提取码；压缩包可再设解压密码，换链接时一起换。
- **合规**：
  - 课程内容须为自有或已获授权。
  - 购买前明确虚拟商品退款规则，下单页勾选确认。
  - 需确认微信 / 支付宝商户的经营类目包含「在线教育 / 知识付费」类，否则可能被风控。
