# 学画画：从 0 到 1（方案设计，未开工）

2026-10-29。在 `hivegpt.cn/learn` 新增一组绘画课程：零基础的人学完以后，想画什么题材都知道该怎么画；同时补上绘画专业知识和艺术鉴赏，提升审美；练习就在课程页里做，不用跳出去。

## 0. 结论

- **定位**：以 **AI 画图**为主要创作手段，用**美术专业知识**讲清楚「为什么这样画好看」，手绘只做辅助（看、想、打草图）。B 路线教的是「工具怎么用」，这一组课教的是「画面怎么想」。
- **三条路线，共约 30 课**：
  - **I 视觉基本功**：观察与形、透视、光影、色彩、构图、镜头、质感、媒介与风格，最后做一次完整创作。
  - **J 题材实战**：人像、动物、风景、建筑、美食、产品、海报、绘本、动漫角色、漫画、国风诗画、Logo 与信息图，一课一张「配方卡」。
  - **K 艺术修养**：怎么看一幅画、中国画、诗书画印、西方美术主线、东亚视觉、设计与摄影、AI 时代的审美与伦理。
- **课内练习是差异化所在**。现在 B 路线只能用 `<TryInCanvas>` 跳到画布；这一组课在页面里就能：
  - 生图并由 AI 按评分表点评；
  - 看名画时切换灰度、构图线和取色；
  - 做眼力题和取色题；
  - 在手绘板上打草图，再让 AI 把草图画成成品。
- **名画素材只用开放授权的馆藏**：大都会博物馆和芝加哥艺术博物馆的 CC0 图像、台北故宫 Open Data。北京故宫的图像不开放授权，不用。
- **分期**：
  - P0：做组件和接口，加 3 节样课，先给你看效果；
  - P1–P3：分三批铺完三条路线的课；
  - P4：证书、每日一练、作品墙。

## 2. 网上的教程是怎么教的（调研摘要）

**传统绘画自学路线**大致都是同一个顺序：
- 线条/造型 → 透视/结构 → 光影/素描 → 色彩 → 构图 → 材质 → 综合创作。
  - 中文教材《零基础绘画自学指南：线条+造型+光影+色彩+材质+透视+构图+创作》按这个顺序分 8 章，造型讲到网格法、负形法、形状归纳法、比例法、倒画法。
  - 知乎上的 2026 年自学指南把它分成三个两月阶段：线条与造型、透视与结构、光影与素描。
- 英文自学圈最常推荐三套免费教程：
  - **Drawabox**：线条、椭圆、方盒子、空间，全是练习，有「250 个盒子」挑战；
  - **Proko**：人体和头部，用 Loomis 方法；
  - **Ctrl+Paint**：数字绘画、明暗、构图。
  - 普遍建议「练习之外也要画着玩，否则容易放弃」。
- **练习工具**：
  - Line of Action / DrawGestures 用 30 秒到 5 分钟的计时速写练动态；
  - 交互色环用来讲配色关系；
  - 「一键看黑白」是检查明度最常用的手段。

**AI 画图的教程**：
- OpenAI 官方的 gpt-image 提示词指南有这几条主要建议：
  - 按「场景 → 主体 → 关键细节 → 约束」的顺序写，并说明用途（广告、UI、信息图）；
  - 写清材质、媒介和镜头，这比堆「8K、超精细」管用；
  - 要出现的文字放在引号里；
  - 改图时说「只改 X，其余不变」，并且每轮都重复要保留的东西；
  - 多张参考图要分别说明各自的作用。
- Midjourney 圈子的教程主要讲三类词：光线词（黄金时刻、逆光、柔光箱）、镜头词（85mm、浅景深、胶片型号）、构图词（三分法、低角度、特写）。

**艺术鉴赏**：
- 中国大学 MOOC 上有北师大《美术欣赏》、武大《西方美术鉴赏》、华中农大《中国传统绘画鉴赏》等课。它们的共同框架有两种：
  - 先讲美术语言和术语，再讲作品和流派，最后讲欣赏方法；
  - 以美术史为纵线、门类为横线。
- 反复推荐的入门书：贡布里希《艺术的故事》、蒋勋《写给大家的中国/西方美术史》、高居翰《图说中国绘画史》、李泽厚《美的历程》。

**我们的取舍**：
- 传统路线里「线条、造型」要练几个月手上功夫，AI 画图用户不需要，这部分压缩成「学会看」一课。
- 透视、光影、色彩、构图、镜头是**看懂和说清画面**的通用语言，AI 画图同样用得上，完整保留。
- 每个知识点都落到三件事：
  1. 名画里是怎么用的；
  2. 提示词里怎么说；
  3. 马上练一次。

## 3. 课程结构

建一个总入口 `/learn/art/`（学画画），下设三条路线，沿用现有 tracks.ts 和 learn_catalog.json 的机制。路线字母从 I 开始（A–H 已占用）。

每一课的固定结构：

1. **看**：一幅名画或一组对比图，用 `<ArtViewer>` 打开构图线、灰度或取色。
2. **懂**：专业知识，配图解。
3. **说**：这个知识点在提示词里怎么写，给出常用词表，并列出哪些词没用。
4. **练**：1–3 个课内练习，形式见第 4 节。
5. **测**：课后测验，沿用现有 Quiz，题目里加看图题。

### 3.1 I 视觉基本功（9 课）

| 课 | 专业知识 | 名画/对比素材 | 课内练习 |
|---|---|---|---|
| i1 学会看：形与剪影 | 形状归纳、剪影、负形、大小对比、「眯眼看」 | 葛饰北斋《神奈川冲浪里》（大都会，CC0）的大形 | 眼力题：剪影认物；手绘板：用 3 个形状概括一张照片 |
| i2 透视与空间 | 视平线、一/二/三点透视、近大远小、遮挡、空气透视；中国画「三远」 | 郭熙《树色平远图》（大都会）对比西方焦点透视 | 眼力题：找视平线；生图：同一条街分别用低视角和俯视画 |
| i3 光影与明暗 | 明度、五调子（亮面、灰面、明暗交界线、反光、投影）、光向（顺光、侧光、逆光、顶光、伦勃朗光）、硬光与软光 | 维米尔《持水罐的年轻女子》（大都会）的窗光 | 对比图：同一人像 4 种光向；手绘板：9 级明度阶梯（自动评分）；生图：只改光线 |
| i4 色彩 | 色相、明度、纯度；冷暖；互补色、类似色、三角配色；固有色、光源色、环境色；色彩情绪 | 修拉《大碗岛的星期天下午》（芝加哥，CC0）、梵高《麦田与柏树》（大都会） | 取色题：从名画里取色配对（按色差打分）；生图：限定 3 种颜色 |
| i5 构图 | 视觉重心、三分法、对角线、S 形、引导线、框中框、对称、留白；为什么「黄金比例」被夸大了 | 马远团扇小品（「马一角」）的留白 | 叠加构图线看名画；手绘板画 3 格缩略图；生图：同一主体 3 种构图 |
| i6 镜头语言 | 景别（远、全、中、近、特写）、视角高低、焦距感、景深、画幅比例 | 电影截帧式的对比图（自己生成） | 眼力题：认景别；生图：同一场景 5 个景别 |
| i7 质感与材质 | 金属、玻璃、布料、皮肤、毛发、水：高光形状与反射 | 对比图：同一个杯子画成 6 种材质 | 生图：用材质词改写产品图 |
| i8 媒介与风格 | 水彩、油画、版画、水墨、铅笔、数字、3D、像素；风格由线、形、色、笔触组合而成；为什么不用在世艺术家的名字 | 同一个村居场景画成 8 种媒介（复用诗画的风格样图） | 眼力题：认媒介；生图：用「特征描述」代替「XX 风格」 |
| i9 综合创作 | 意图 → 找参考 → 缩略图 → 生图 → 点评 → 局部修改 → 定稿 | — | 结业作品：完整走一遍，提交给 AI 按评分表打分 |

### 3.2 J 题材实战（12 课）

每课一张「配方卡」，内容包括：

- 这个题材画得好的关键要素；
- 常用构图和光线；
- 风格词；
- 常见的出错情况和修法（例如手指、文字、比例、一致性）；
- 2–3 个可直接用的模板，链接到提示词库对应分类。

然后完成一个**命题练习**，AI 按题材评分表点评。

## 4. 课内练习（新组件）

都是 `learn/.vitepress/theme/components/` 下的 Vue 组件。页面有 nonce CSP，所以继续不写行内脚本。

| 组件 | 做什么 | 花钱吗 |
|---|---|---|
| `<ArtViewer src credit>` | 看名画：缩放、**灰度**（看明度）、**模糊**（看大形）、**镜像**、叠加三分线/对角线/黄金螺旋、**取色板**（自动提取 5 色）、热点批注 | 不花，纯前端 |
| `<CompareGrid>` | 一次只改一个变量的对比图，例如 4 种光向、5 个景别、8 种媒介。图由脚本提前生成 | 不花（制作时一次性花） |
| `<EyeQuiz>` | 看图选择题：这是什么构图、光从哪来、哪个流派。即时判分，答案只在服务端 | 不花 |
| `<ColorMatch>` | 从名画里取一个颜色，用色相、明度、纯度滑块调出来，按色差 ΔE 打分，顺带教 HSB | 不花 |
| `<SketchPad mode>` | 浏览器手绘板，支持压感和撤销。几种模式：<br>· 线条：直线和椭圆按几何偏差自动打分；<br>· 明度阶梯：采样灰度、检查是否均匀；<br>· 缩略图：3 格构图草图；<br>· 临摹：把参考图半透明叠在下面 | 打分不花；「AI 点评草图」和「草图变成画」按下面两项计费 |
| `<DrawBox>` | **课内生图**，详见下文 | 免费次数用管理员学习 Key，之后用自己的 Key |
| `<CritiqueBox>` | 提交自己的画（生成的、手绘的或上传的）或一段赏析文字，AI 按评分表点评 | 同上 |

**`<DrawBox>` 的设计**（核心组件）：
- **命题**：一句任务，例如「画一张侧光人像，光从左边来」，附一段起步提示词。可以锁定部分字段，比如只允许改「光线」这一行，逼学员只调一个变量。
- **生图**：在课程页里出图，默认低质量 1K 以控制成本，画幅可选。网关会自动补上画幅提示（`openai_image_aspect_hint`）。
- **点评**：出图后自动送视觉模型，按这道题的评分表（存在服务端 catalog）逐项打分，给一条改进建议，再给一版改过的提示词。
- **对比**：保留本题的历史结果，可以和上一张并排看；「改一个地方再画」直接带上次的提示词。
- **出口**：「在画布里继续」（深链到生图工作台）、「加入我的练习册」、「发布到作品墙」。

## 5. 后端

- **接口**（`/api/v1/learn/*`，登录可用）：
  - `POST /learn/draw`：`{lesson, exercise, prompt, size, sketch?, key_id?}`。经本机网关回环调用 `/v1/images/generations`；带草图时调用 `/v1/images/edits`，草图不超过 2 MB。
  - `POST /learn/critique`：`{lesson, exercise, practice_id | image | text, key_id?}`。用视觉模型和评分表点评，返回 `{scores: [{dim, score, note}], suggestion, revised_prompt}`。
  - `GET /learn/practice?lesson=`：我的练习记录。
- **数据**：新表 `learn_practice_works`，字段有 user_id、lesson、exercise、prompt、image_url、scores、public、created_at。生成的图存到现有的作品/资产存储，P0 时确认用哪一个。
- **题库**：练习的命题、评分表和眼力题答案放进 `learn_catalog.json`，和测验一样不下发到页面。`TestLearnCatalogMatchesSite` 扩展到检查练习 ID。
- **额度**（`/admin/learn` 加设置项）：
  - 免费生图：默认每人每天 2 张，低质量；
  - 免费点评：默认每人每天 10 次；
  - 全站每日上限。
  - 免费次数用完，提示选自己的 Key，正常计费（沿用 `OwnKeyPicker`）。
  - 成本参考：10-05 批量生成配图时 111 张约 22.3 美元，即高质量每张约 0.2 美元；低质量需要实测。
- **安全**：
  - 生图请求走正常网关，内容审核照旧；
  - 课程里明确提示不画真人、不画国家标志；
  - 点评结果不展示原始模型输出以外的内容。

## 6. 证书与留存

- **I 证书**：每课测验 ≥80%，并且结业作品（i9）点评总分 ≥70。
- **J 证书**：至少 6 个题材各有 1 张练习作品点评 ≥70，并公开到作品墙。
- **K 证书**：测验 ≥80%，并且 3 篇赏析点评 ≥70。
- 三张都拿到，发总证书「学画画 · 从 0 到 1」，沿用现有证书海报和邀请码。
- **P4 再做**：
  - 每日一练：每天一个 10 分钟小命题，全站同题，可以看别人怎么画；
  - 打卡日历；
  - 作品墙按课筛选。

## 7. 内容制作

- **课文**：自己写，结构参考第 2 节的调研，不搬运 Drawabox 或书里的原文。每课写完核对事实：功能名、画布路径、模型行为都以线上为准。
- **名画素材**：写 `learn/scripts/import_artworks.py`，从大都会和芝加哥的开放 API 按清单拉图，转成 WebP 放进 `learn/public/art/`。
  - 每张记录作者、标题、年代、馆藏和授权；`<ArtViewer>` 自动显示署名。
  - 芝加哥要求署名格式为「艺术家.《标题》, 年代. The Art Institute of Chicago」。
- **对比图**：扩展 `gen_bigdata_images.py`，新增 `--set art`。
  - 预计约 30 课 × 8 张 ≈ 240 张，按高质量单价估约 50 美元；
