# HTML 网站发布（设计稿，未开发）

目标：付费用户上传 HTML（单文件或 zip 包），一键得到一个可访问的网址；AI 生成的网页（画布 / 对话里产出的 HTML）可以直接发布。

## 1. 结论：不基于 CloudFlare-ImgBed，在主站内自建模块

调研了 MarSeventh/CloudFlare-ImgBed（MIT 协议，6.5k star，活跃维护），它不适合当底座：

| 需求 | ImgBed 现状 |
|---|---|
| 多用户、每个用户自己的文件和配额 | 没有用户体系：一个管理员账号 + 一个共享上传口令；API Token 都等同管理员（多用户需求 issue #701 仍未实现） |
| 只给付费用户用、按量计费 | 没有按用户的配额，只按存储渠道统计 |
| 把 HTML 当网站访问（index.html、子目录、zip 站点、独立网址） | 不支持，只是图床 / 文件床，文件夹只是分类 |
| 安全托管用户 HTML | 上传时用客户端声明的 Content-Type、inline 返回、无 nosniff / CSP / 后缀白名单，上传的 .html/.svg 会在图床同域下执行（存储型 XSS，issue #474） |
| 和本站部署方式一致 | 代码是 Cloudflare Pages Functions（JS）；Docker 版是自己模拟 CF 运行时 + SQLite，要多维护一套 JS 服务、一套账号和数据库 |

能借鉴的只有思路：分片上传协议、多存储渠道（本地 / S3 / R2）抽象、上传后审核钩子。这些在 Go 里重写的工作量很小，而且能直接复用本站的用户、余额、订阅、后台和风控。

## 2. 域名：xinduanju.top 的子域名（已定，有风险需要知晓）

用户网站绝不能放在 `hivegpt.cn` 下：用户页面的脚本会和主站同站（same-site），能读写 `.hivegpt.cn` 范围的 Cookie；一旦有页面被举报钓鱼，整个 hivegpt.cn 会被浏览器 / 微信拦截。

采用 `xinduanju.top`：每个站点是 `<站点名>.s.xinduanju.top`（多一级 `s`，不占用 xinduanju.top 本身和 www）。现状：xinduanju.top 解析到另一台服务器（39.99.241.178，阿里云），DNS 在阿里云（hichina）。

需要知道的风险（因为 xinduanju.top 上还有别的部署）：
- **同站风险转移到 xinduanju.top**：用户页面和 xinduanju.top 上的其他服务是同一个根域名。如果那边的服务有登录，Cookie 必须是不带 `Domain=` 的仅本主机 Cookie，否则用户页面能读写它。
- **被拦截会连带**：用户页面被举报钓鱼时，浏览器、微信、QQ 可能拦截整个 xinduanju.top，包括那边的部署。
- **备案**：如果 xinduanju.top 做过 ICP 备案，用户发布违规内容可能被追责到备案主体。
- 能接受就用；不能接受的话，另买一个只做托管的便宜域名，代码不需要改（托管域名是配置项）。

需要你在阿里云 DNS 加一条解析：`*.s` → A → 43.133.80.169（首尔服务器）。证书两种做法：
- 泛域名证书 `*.s.xinduanju.top`（推荐）：Caddy 用阿里云 DNS 验证，需要一个只有该域名 DNS 修改权限的阿里云 AccessKey（RAM 子账号，你自己创建并填到服务器上）；
- 按需签发（每个站点单独签）：不用 AccessKey，但 Let's Encrypt 每周每个根域名最多签 50 张，站点多了会不够。

## 3. 用户能做什么

- **发布**：上传单个 `.html`，或一个包含 `index.html` 的 `.zip`（带 css/js/图片），或者在画布 / 对话里点「发布为网页」把 AI 生成的 HTML 直接发出去。
- **站点名**：自动生成（如 `k3f9a2`），付费等级高的可以自定义（3–32 位小写字母数字和连字符，保留词和敏感词禁用）。
- **更新**：重新上传覆盖，保留最近 N 个版本可回滚。
- **管理**：我的站点列表、访问量、下线 / 删除、设置访问密码（可选）。
- **入口**：主站「我的网站」页面 + 开放 API（用 API Key 发布，方便 Agent / 脚本自动部署）。

## 4. 谁能用、怎么收费（已定）

- **开通条件**：只有当前订阅中的用户能发布；只买按量额度的用户不开通。
- **订阅到期**：进入宽限期（建议 7 天，后台可配），宽限期内站点照常访问、不能新建/更新，并在主站和站点管理页提醒续费；宽限期结束后站点下线（文件保留 30 天，续费后恢复，超过 30 天删除）。
- **配额**：每人 3 个站点，单站 20 MB（zip 解压后）。
- **收费**：订阅自带一部分免费额度（建议：1 个站点 + 20 MB），超出部分从余额扣费，两种计费方式后台二选一：
  - 按站点：每多一个站点 X 元/月；
  - 按大小：超出免费额度的部分按 Y 元/MB·月。
  每日结算，余额不足时先提醒，连续 N 天不足则下线超出额度的站点（保留最早的免费额度内站点）。
- 后台按订阅套餐配置：免费站点数、免费容量、宽限天数、计费方式和单价。

## 5. 安全与合规（这一块是成本大头，必须做）

托管用户网页最大的风险是被用来做钓鱼、诈骗、赌博、色情页面，导致域名被封、服务器被投诉。

上传时：
- zip 解压防路径穿越（zip-slip）、限制解压后总大小 / 文件数 / 压缩比（防 zip 炸弹）、拒绝符号链接。
- 文件后缀白名单：html/htm/css/js/json/txt/md/svg/png/jpg/jpeg/gif/webp/ico/woff/woff2/ttf/mp3/mp4/webm；拒绝 exe/apk/dmg/sh/bat/php 等。不支持服务端代码，纯静态。
- Content-Type 由服务端按后缀决定，不信任客户端声明。
- 自动审核：抽取页面文字送内容审核（可用本站网关的模型或第三方文本审核），命中「登录 / 输入密码 / 银行卡 / 验证码 / 仿冒知名品牌」等特征的页面进入人工审核，审核通过前不公开。

访问时：
- 所有响应加 `X-Content-Type-Options: nosniff`、`Referrer-Policy`；禁止页面里提交表单到第三方（CSP `form-action 'self'`），降低钓鱼价值。
- 每个页面底部（或右下角）加一个不可去除的小角标「由 HiveGPT 托管 · 举报」，举报直达后台。
- 后台：站点列表、一键下线、封禁用户发布权限、举报队列、审核队列。
- 用户协议补充：禁止内容清单、违规直接删除不退款。

## 6. 技术方案

```
上传：主站前端 / API  ──>  sub2api 后端（鉴权、配额、解压、校验、审核）──>  存储
访问：<名>.<托管域名>  ──>  Caddy（泛域名证书）──>  sub2api 后端「站点服务」按 Host 找站点 ──>  存储
```

- **复用 sub2api 进程**，新增 `sites` 模块（service / repository / handler），不另起服务。站点访问请求由同一进程按 Host 分流（只认托管域名，主站域名上不提供这些路由）。
- **存储**：MVP 用服务器本地磁盘（`<data>/sites/<site_id>/<version>/`，当前服务器剩余 93GB）；接口按「存储驱动」抽象，后续可切到腾讯云 COS / Cloudflare R2，并在前面加 CDN。
- **数据库**（新增迁移）：
  - `sites`：id、user_id、name（唯一）、status（active/pending_review/disabled/banned）、current_version、size_bytes、file_count、password_hash、views、bytes_served、created_at…
  - `site_versions`：site_id、version、size、file_count、manifest(jsonb：路径→大小/哈希)、created_at
  - `site_reports`：site_id、reason、reporter_ip、status
  - 流量 / 访问量用 Redis 计数，定时落库。
- **路由规则**：`/` 和 `/xx/` 找 `index.html`；找不到时返回站点的 `404.html` 或默认 404；可选「单页应用」模式把未知路径都回落到 `index.html`。
- **缓存**：静态文件带 ETag + `Cache-Control: public, max-age=300`；版本更新后立即生效。
- **画布对接**：画布 / Agent 生成 HTML 后调用 `POST /api/v1/sites`（API Key 鉴权，与提示词库同一套 companion 接口），返回网址。
