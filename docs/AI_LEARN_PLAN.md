## 2. 用户能做什么

### 2.1 学习路线（首批两条，后续两条）

| 路线 | 面向 | 课时（每课 10–20 分钟） | 结业项目 |
|---|---|---|---|
| **A. AI 应用开发入门** | 后端 / 前端开发、计算机学生 | 1 第一次调用大模型 API（拿 Key、curl / Python / JS）→ 2 流式输出和多轮对话 → 3 结构化输出 → 4 Function Calling → 5 Embedding 和 RAG 问答 → 6 Agent 循环 → 7 MCP 入门 → 8 上线：成本、限流、错误重试 | 做一个网页聊天 / 问答机器人，用「网站托管」发布出去 |
| **B. AI 绘画与视频创作** | 设计、运营、自媒体、零基础 | 1 提示词的结构 → 2 用提示词模板 → 3 参考图和图生图 → 4 局部编辑、扩图、抠图 → 5 视频生成 → 6 发布作品和做同款 → 7 参加比赛 | 在画布社区发布一个作品集（≥3 张） |
| C. AI 编程助手上手（L2） | 想用 AI 写代码的人 | 配置客户端接入 HiveGPT → 让 AI 写一个网页 → 调试和改需求 → 发布 | 用编程助手做一个小网站并发布 |
| D. AI 面试训练（L2） | 求职学生 | 按大模型基础 / Agent / RAG / 系统设计分组的题库 + 模拟面试 | 完成 4 组模拟面试 |

课程内容由我起草、你审核后上线；价格、模型名、按钮位置都引用站内真实功能，不写没上线的能力。

### 2.2 课时页里的互动组件

- **运行按钮**：代码块旁边有「运行」，用当前登录用户的余额真实调用一次（限定便宜模型、限制 max_tokens），结果在下方显示。可以改代码块里的提示词再运行。没登录时显示「登录后运行」，并附上录好的示例输出。
  - 每人每天有 20 次免费运行（后台可调），用完后按正常价格扣余额。
- **提示词练习台**（路线 B）：输入提示词，用便宜的图片模型出一张小图，可以「在画布里打开」继续做。
- **AI 助教**：右侧抽屉，带着本课内容回答问题。每天免费 10 问，超出按量扣余额。
  - 助教只回答和课程相关的问题。
  - 每轮限制上下文和输出长度。
- **小测验**：每课 3–5 道选择 / 判断题，答案在服务端判分，不放在网页里。
- **检查点**：例如「在你的 Key 页面新建一个 Key」「在画布发布一张图」。点「我做完了」后由服务端核对（查有没有对应记录），不只是点一下就算。

## 4. 技术方案

```
learn/                         主站仓库新目录
  content/<track>/<lesson>.md  课程正文；frontmatter 写 id、时长、目标、测验、检查点
  .vitepress/                  VitePress 主题：沿用主站样式，自定义 <RunCode> <Quiz> <Checkpoint> <Tutor>
  build → dist/                静态 HTML（利于搜索收录）+ catalog.json（课时清单 / 测验答案 / 检查点规则）
```

- **静态生成用 VitePress**：
  - 和主站一样是 Vue，组件和样式可以复用。
  - 输出静态 HTML，搜索引擎能收录，自带中文全文搜索。
- **部署**：
  - Dockerfile 加一个构建阶段，把 `learn/dist` 一起打进镜像。
  - Go 服务在 `/learn/*` 返回这些静态文件（有自己的 404 页），不进 SPA 的兜底路由。
  - 内容更新跟随正常发版，不用再手工上传。
- **登录态**：
  - 同域名，互动组件直接用主站存的登录令牌（`auth_token`）调 `/api/v1/learn/*`。
  - 没登录时跳主站登录，登录后回到原课时。
- **测验答案和检查点规则**：放在 `catalog.json` 里，由后端读取，不下发到网页；页面只拿到题目。
- **后端（Go，原生 SQL，与社区模块同样写法）**：

| 接口 | 说明 |
|---|---|
| `GET /api/v1/learn/progress` | 我的各路线进度、已完成课时、证书 |
| `POST /api/v1/learn/lessons/:id/complete` | 标记完成（课时需要的测验 / 检查点都过了才算） |
| `POST /api/v1/learn/quiz/:lesson_id` | 提交答案，服务端判分，返回对错和解析 |
| `POST /api/v1/learn/checkpoints/:id/verify` | 服务端核对，例如有没有 Key、有没有调用记录、有没有发布作品 |
| `POST /api/v1/learn/run` | 运行代码块：只允许白名单模型和端点，限 max_tokens / 超时；先用每日免费次数，再走用户余额计费；计费和用量记录复用网关现有流程 |
| `POST /api/v1/learn/tutor` | AI 助教，流式返回；系统提示词带本课正文摘要；同样先免费后计费 |
| `GET /learn/cert/:code`（公开） | 证书验证 |
| 后台 `GET/PUT /api/v1/admin/learn/settings`、`GET /admin/learn/stats` | 免费次数、助教模型、奖励开关；学员数、各课完成漏斗 |

- **数据表**：
  - `learn_progress`（user_id, lesson_id, status, quiz_score, completed_at）。
  - `learn_free_usage`（user_id, day, runs, tutor_questions）。
  - `learn_certificates`（code, user_id, track, issued_at, project_url）。
- **免费额度的成本**：运行和助教都走便宜模型。每次花费约 ¥0.005–0.02，每人每天 20 + 10 次，100 个活跃学员一个月成本约百元以内。后台可以随时调低或关掉。
- **防滥用**：
  - 免费次数只给已验证邮箱的账号。
  - 运行接口不接受任意参数，只执行课程里预设的请求模板，允许改的只有提示词那一段。
  - 助教限制每轮长度。
- **迁移**：
  - 旧站每个页面按 `pages.json` 一一 301 到 `/learn/guide/...`。
  - 主站首页的「AI 学习」入口改成站内链接。
  - 旧服务器保留跳转规则至少 3 个月。
