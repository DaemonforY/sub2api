# HiveGPT 站点常见问题（智能客服知识库）
#
# 每个「## 」是一条资料：第一行可写「链接：/路径」，作为回答里的参考链接。
# 价格、比例、优惠会调整：这里只写做法和入口，具体数字让用户以页面为准。

## HiveGPT 是什么
链接：/
HiveGPT（hivegpt.cn）是一个 AI 服务聚合平台：注册一个账号、创建一个 API Key，就能调用 GPT、Codex 等模型，在无限画布里画图，接入 Codex、Claude Code、OpenCode 等编程工具。站内还有 AI 学习站、公众号排版工具、创作比赛和付费课程。

## 怎么注册和登录
链接：/register
在首页点「注册」，用邮箱注册（也可能提供第三方登录，以登录页为准）。有邀请链接时用邀请链接注册，邀请奖励会自动绑定。忘记密码在登录页点「忘记密码」用邮箱重置。

## 怎么创建 API Key
链接：/keys
登录后进入控制台「API 密钥」，点「创建密钥」，给 Key 起名并选择分组（分组决定能用哪些模型和怎么计费）。创建后可以随时停用、删除，或为每个 Key 设置额度上限和过期时间。Key 只在自己的工具里使用，不要发给别人；如果泄露了，删除后重新创建一个。

## 怎么在 Codex、Claude Code 等编程工具里使用
链接：/keys
在「API 密钥」页点某个 Key 的「使用密钥」，会生成对应工具的配置，复制粘贴即可。详细步骤见 AI 学习站的 Codex 教程「接入 HiveGPT」（/learn/codex/hivegpt）。Codex 用 GPT 分组的 Key。

## 网关地址（Base URL）是什么
链接：/keys
接口地址是 https://hivegpt.cn ，OpenAI 兼容接口在 https://hivegpt.cn/v1 下（如 /v1/chat/completions、/v1/responses、/v1/images/generations）。具体工具怎么填，以「使用密钥」弹窗生成的配置为准。

## 支持哪些模型
链接：/model-plaza
已开放的模型以「模型广场」和「可用渠道」页为准，会持续增加。每个分组能用的模型不同，创建 Key 时选对分组。

## 怎么收费、怎么充值
链接：/purchase
按实际用量计费，按模型的官方美元标价计算 token 用量，用多少扣多少。充值按 ¥1 = $1 额度到账，在「充值 / 订阅」页选择金额，用页面提供的方式支付。每次调用的模型、token 数和扣费都能在「使用记录」里查到。具体价格以页面显示为准。

## 画图、生图怎么收费
链接：/available-channels
画图（如 gpt-image-2）按张计费，价格随图片尺寸和质量不同，按所用 Key 的分组计费；订阅套餐里的画图用量从订阅额度里扣。每个分组的模型和价格以「可用渠道」「模型广场」页为准，每次出图的扣费在「使用记录」里能查到。

## 订阅套餐
链接：/purchase
经常用 Codex 等编程工具，可以在「购买订阅」页选订阅套餐：订阅期内按套餐的每日 / 每周 / 每月额度使用，比按量更省心。套餐种类、价格和额度以购买页为准；已购订阅在「我的订阅」查看。

## 学生、教师优惠（教育认证）
链接：/profile
学生或老师可以在「个人资料」页（或购买订阅时的结算页）用学校邮箱（如 edu.cn）完成教育认证，认证后订阅套餐有折扣，折扣以页面显示为准。学校没有教育邮箱的，可以联系客服人工审核。

## 邀请好友返利
链接：/affiliate
在「邀请返利」页复制自己的邀请链接或海报，好友通过链接注册并消费后，你可以获得返利，好友也有新人奖励。具体比例、有效期和到账规则以邀请页说明为准。

## 用量、账单和订单在哪里看
链接：/usage
「使用记录」里有每次调用的明细和费用；「我的订单」里是充值和购买记录；没有登录也可以在 /key-usage 页面输入 Key 查询这个 Key 的用量（Key 只在浏览器本地处理）。

## 兑换码怎么用
链接：/redeem
在控制台「兑换」页输入兑换码，额度或订阅会直接到账。

## 无限画布（画图、改图）
链接：https://canvas.hivegpt.cn
无限画布（canvas.hivegpt.cn）是免费的创作界面：文生图、改图、扩图、抠图、超分，节点连线出图。真正的出图由你的 API Key 调用本站完成，按 Key 所在分组计费；从本站侧边栏「AI 应用 → 无限画布」进入时会自动连好本站。作品、历史和 Key 默认只保存在你的浏览器里，可以一键投稿站内创作比赛。

## 公众号排版工具
链接：/editor/
公众号排版（hivegpt.cn/editor）：Markdown 或公众号文章链接一键排版，19 种风格，复制到公众号后台；登录后可以让 AI 润色、配图，并填好公众号的 AppID / AppSecret 后一键发到草稿箱。AppID、AppSecret 和 IP 白名单在微信开发者平台「我的业务 → 公众号 → 基础信息 → 开发密钥」获取和设置，需要把服务器 IP 43.133.80.169 加入 API IP 白名单。完整教程见 /learn/editor/ 。

## AI 学习站
链接：/learn/
AI 学习站（hivegpt.cn/learn）有 AI 应用开发路线（从调用 API 到做 Agent）、Codex 教程、大数据（Spark / Flink / Paimon）源码与面试题、延伸阅读等，课时里的示例可以用自己的 Key 在线运行，学完可以考取结业证书。登录后在控制台「我的学习」查看进度。

## 付费课程
链接：/courses
「付费课程」页列出在售的课程，购买后在「我的课程」里查看和领取资料。

## 创作比赛
链接：/contests
「创作比赛」页有正在进行的活动，可以用无限画布创作后投稿，规则和奖励以活动页为准。

## 网站发布（我的网站）
链接：/sites
「我的网站」可以把 HTML 网页一键发布成网站：上传一个 .html 文件，或一个包含 index.html 的 .zip 压缩包，马上得到可以分享的网址。订阅用户专享。

## 批量生图
链接：/batch-image
「批量生图」用开启了批量生图的 Gemini 分组 Key，一次提交多条提示词（可带参考图、设置每条张数）排队出图，完成后打包下载 ZIP，按成功出图张数计费。开放情况以页面为准。

## 渠道状态、服务不可用
链接：/monitor
「渠道状态」页显示各渠道的可用情况。调用报错「Service temporarily unavailable」或「no available account」时，通常是对应分组的上游暂时不可用，可以稍后重试，或换用其他可用分组的 Key；持续出现请联系客服。

## 常见报错
链接：/usage
401 / invalid api key：Key 填错、已删除或已停用，检查 Key 或重新创建。余额不足 / quota：充值或检查 Key 的额度上限、订阅是否到期。429：请求太频繁或达到额度限制，稍后再试。模型不存在：这个分组不支持该模型，换分组或换模型。

## 隐私和安全
链接：/
网关只转发请求并记录计费所需的用量信息。不要把 API Key、密码、公众号 AppSecret 发给任何人（包括客服）；如果在聊天里或公开场合泄露了 Key，请立即在「API 密钥」页删除并重新创建。
