#
# 每个「## 」是一条资料：第一行可写「链接：/路径」，作为回答里的参考链接。
# 价格、比例、优惠会调整：这里只写做法和入口，具体数字让用户以页面为准。

## HiveGPT 是什么
链接：/
HiveGPT（hivegpt.cn）是一个 AI 服务聚合平台：注册一个账号、创建一个 API Key，就能调用 GPT、Codex 等模型，在无限画布里画图，接入 Codex、OpenCode 等编程工具（暂不支持 Claude Code）。站内还有 AI 学习站、公众号排版工具、创作比赛和付费课程。

## 怎么注册和登录
链接：/register
在首页点「注册」，用邮箱注册（也可能提供第三方登录，以登录页为准）。有邀请链接时用邀请链接注册，邀请奖励会自动绑定。忘记密码在登录页点「忘记密码」用邮箱重置。

## 登录或注册要输入图形验证码、提示失败次数过多
链接：/login
为了防止批量猜密码和批量注册：同一网络或同一邮箱连续登录失败几次后，登录页会出现图形验证码；同一网络短时间内发了几次注册验证码、或当天已经注册过两个账号，注册时要先输入图形验证码再点「重新发送验证码」。输入图中 4 个字符（不区分大小写），看不清可以点图片换一张，每张只能用一次。同一网络 15 分钟内失败太多次（密码错、邮箱验证码错、图形验证码错都算）会被暂停登录和注册 15 分钟，到时间自动恢复。记不清密码就在登录页点「忘记密码」用邮箱重置，比反复尝试更快。

## 怎么创建 API Key
链接：/keys
登录后进入控制台「API 密钥」，点「创建密钥」，给 Key 起名并选择分组（分组决定能用哪些模型和默认怎么计费；有订阅时会自动先用订阅额度，不用为订阅和按量各建一个 Key）。创建后可以随时停用、删除，或为每个 Key 设置额度上限和过期时间。Key 只在自己的工具里使用，不要发给别人；如果泄露了，删除后重新创建一个。

## 怎么在 Codex 等编程工具或自己的代码里使用（接入教程）
链接：/learn/connect/
在「API 密钥」页点某个 Key 的「使用密钥」，会生成 Codex、OpenCode 等工具的配置，复制粘贴即可。各种用法的教程在 AI 学习站「接入教程」（/learn/connect/）：Codex 看「接入 HiveGPT」（/learn/codex/hivegpt）；OpenCode、CodeBuddy、Cherry Studio、Chatbox 等支持 OpenAI 兼容接口的工具看「在常用工具里配置」（/learn/connect/tools）；Python、Node.js、curl 看「用 SDK 调用」（/learn/connect/sdk）。Codex 要用 GPT 分组的 Key。

## 能用 Claude Code 吗
链接：/learn/connect/
暂不支持 Claude Code。编程工具请用 Codex（教程 /learn/codex/hivegpt）或 OpenCode（/learn/connect/tools），对话客户端可以用 Cherry Studio（/learn/connect/cherry-studio）、Chatbox（/learn/connect/chatbox）。以后开放会在首页和学习站说明。

## 网关地址（Base URL）是什么
链接：/keys
接口地址是 https://hivegpt.cn ，OpenAI 兼容接口在 https://hivegpt.cn/v1 下（如 /v1/chat/completions、/v1/responses、/v1/images/generations）。具体工具怎么填，以「使用密钥」弹窗生成的配置为准。

## 支持哪些模型
链接：/learn/connect/
每个分组能用的模型不同，以接口返回为准：用自己的 Key 请求 https://hivegpt.cn/v1/models 就能看到可用模型列表；Codex 用户也可以在「使用密钥」弹窗里点「获取目录」。创建 Key 时选对分组，选错分组是「模型不可用」最常见的原因。

## 怎么收费、怎么充值
链接：/purchase
按实际用量计费，按模型的官方美元标价计算 token 用量，用多少扣多少。充值按 ¥1 = $1 额度到账，在「充值 / 订阅」页选择金额，用页面提供的方式支付。每次调用的模型、token 数和扣费都能在「使用记录」里查到。按量和订阅怎么选，可以看价格页（/pricing），那里有在售套餐的额度对比和按用量估算。具体价格以页面显示为准。

## 画图、生图怎么收费
链接：/pricing
画图（如 gpt-image-2）按张计费，价格随图片尺寸和质量不同，按所用 Key 的分组计费；订阅套餐里的画图用量从订阅额度里扣。按量和订阅怎么计费看价格页（/pricing），每次出图实际扣了多少在「使用记录」里能查到；想先试试效果可以用无限画布。

## 订阅套餐、订阅和按量怎么选
链接：/pricing
经常用 Codex 等编程工具，可以选订阅套餐：订阅期内按套餐的每日 / 每周 / 每月额度使用，用量大且稳定时比按量划算；偶尔用或想先试试，用按量付费。价格页（/pricing）列出在售套餐的价格、额度和折算，还能按每天的请求次数估算哪种更省。买了订阅后不用换 Key：同一个 Key（按量分组的也行）在对话和 Codex 请求里会先用订阅额度，订阅额度用完或到期后自动改用余额继续，余额不足才会报错；画图、视频等仍按 Key 所在分组计费。每次请求实际用的分组在「使用记录」里能看到。套餐种类、价格和额度以购买页为准；已购订阅在「我的订阅」查看。

## 学生、教师优惠（教育认证）
链接：/profile
学生或老师可以在「个人资料」页（或购买订阅时的结算页）用学校邮箱（如 edu.cn）完成教育认证，认证后订阅套餐有折扣，折扣以页面显示为准。学校没有教育邮箱的，可以联系客服人工审核。

## 邀请好友返利
链接：/affiliate
在「邀请返利」页复制自己的邀请链接或海报，好友通过链接注册并消费后，你可以获得返利，好友也有新人奖励。返利可以一键转入余额使用；平台开放提现时，也可以申请提现到支付宝或微信。具体比例、有效期和到账规则以邀请页说明为准。

## 返利能提现吗、怎么提现
链接：/affiliate
平台开放提现后，「邀请返利」页会出现「返利提现」：填支付宝或微信收款账号和真实姓名（要和账号实名一致），输入金额申请，人工审核后打款，一般 1–3 个工作日到账，打款前可以自己撤销。只有好友用支付宝 / 微信等真实付费、已过冻结期的返利能提现，按好友实际付款（不含手续费）折算成人民币；后台赠送、兑换码、余额支付带来的返利只能转入余额。已经转入余额的返利不能再提现。最低金额和每月次数以页面显示为准；被驳回时返利会退回，驳回原因在提现记录里能看到。没有看到「返利提现」说明暂未开放，返利可以先转入余额使用。

## 用量、账单和订单在哪里看
链接：/usage
「使用记录」里有每次调用的明细和费用；「我的订单」里是充值和购买记录；没有登录也可以在 /key-usage 页面输入 Key 查询这个 Key 的用量（Key 只在浏览器本地处理）。

## 兑换码怎么用
链接：/redeem
在控制台「兑换」页输入兑换码，额度或订阅会直接到账。

## 无限画布（画图、改图）
链接：https://canvas.hivegpt.cn
无限画布（canvas.hivegpt.cn）是免费的创作界面：文生图、改图、扩图、抠图、超分，节点连线出图。真正的出图由你的 API Key 调用本站完成，按 Key 所在分组计费；从本站侧边栏「AI 应用 → 无限画布」进入时会自动连好本站。作品、历史和 Key 默认只保存在你的浏览器里，可以一键投稿站内创作比赛。

## 公众号排版工具
链接：/editor/
公众号排版（hivegpt.cn/editor）：Markdown 或公众号文章链接一键排版，19 种风格，复制到公众号后台；登录后可以让 AI 润色、配图，并填好公众号的 AppID / AppSecret 后一键发到草稿箱。AppID、AppSecret 和 IP 白名单在微信开发者平台「我的业务 → 公众号 → 基础信息 → 开发密钥」获取和设置，需要把服务器 IP 43.133.80.169 加入 API IP 白名单。完整教程见 /learn/editor/ 。

## AI 学习站
链接：/learn/
AI 学习站（hivegpt.cn/learn）有场景玩法（按身份找 AI 用法，不用写代码，/learn/scenes/）、AI 应用开发路线（从调用 API 到做 Agent）、Codex 教程、大数据（Spark / Flink / Paimon）源码与面试题、延伸阅读等，课时里的示例可以用自己的 Key 在线运行，学完可以考取结业证书。登录后在控制台「我的学习」查看进度。

## AI 能帮我做什么、不知道怎么用起来（场景玩法）
链接：/learn/scenes/
AI 能做的远不止写代码和做 PPT。AI 学习站的「场景玩法」（/learn/scenes/）按身份整理了用法，每个场景都有以前怎么做、用 AI 怎么做、可以直接复制的提示词和注意事项，登录后页面里的「动手试试」可以直接运行。用法分三个层次：聊天问答（写邮件、改文案、出点子）→ 让 AI 处理你的文件（会议纪要、合同对比、读论文、整理表格）→ 让 AI 自己动手（用 Codex 批量整理文件、合并 Excel、抓网页、定时汇总）。不知道怎么问可以先看「提示词心法」（/learn/scenes/prompting）。日常聊天可以按「在常用工具里配置」（/learn/connect/tools）装 Cherry Studio 或 Chatbox，填上自己的 Key。

## 我是老师、学生、销售、上班族……AI 怎么用在我的工作里
链接：/learn/scenes/
按身份看「场景玩法」里对应的一篇：办公室日常（邮件、会议纪要、周报、整理表格、合同对比）/learn/scenes/office；销售与运营（客户跟进话术、竞品整理、活动方案、数据复盘）/learn/scenes/sales；老师（教案、出题与批改、家长沟通、课件）/learn/scenes/teacher；学生（学习计划、读论文、练口语、简历与面试）/learn/scenes/student；财务与数据（Excel 公式、数据清洗、用 Codex 处理本地 Excel）/learn/scenes/data；自媒体与内容（选题、公众号排版、配图、短视频脚本）/learn/scenes/content；个人生活（旅行、记账、看懂体检单、家庭事务）/learn/scenes/life；小老板与个体户（客服话术、商品描述、合同初审）/learn/scenes/business。涉及钱、健康、法律的决定，AI 只帮你整理信息，拍板请找专业人士；重要的事实要自己核对。

## 怎么让 AI 自动处理文件、批量整理表格、定时干活（自动化）
链接：/learn/scenes/automation
用 Codex（桌面应用或命令行）可以让 AI 在你的电脑上动手：批量重命名和整理文件夹、Word / PDF 转格式并提取信息、合并几十个 Excel、把网页内容整理成表格、每天定时生成汇总。入门看「自动化入门」（/learn/scenes/automation）：先在 API 密钥页用 GPT 类分组的 Key 点「使用密钥」复制 Codex 配置，把要处理的文件复制到一个专门的文件夹，在里面打开 Codex，用中文说清楚要什么，并要求先处理几个给你看。具体例子见「批量处理文件和表格」（/learn/scenes/automation-files）、「网页整理与浏览器操作」（/learn/scenes/automation-web）、「定时任务和一键小工具」（/learn/scenes/automation-schedule）。安全要点：先在副本上试；看清它要执行的命令再批准；不要把 Key、密码发给它；不要给完全访问权限。

## 发布自己的课程（创作者中心）
链接：/creator
想在站内卖自己的课程，可以在「创作者中心」申请成为创作者（开放申请时才能提交），平台审核通过后就能建课：写介绍、大纲和价格，填好百度网盘链接后提交审核，通过后上架。之后改介绍或价格要重新审核，网盘链接随时可以换、立即生效。学员付款后自动在「我的课程」拿到网盘链接。每卖出一份，平台按学员实付金额收取一定比例的手续费，具体比例、结算天数和最低提现金额以创作者中心页面显示为准；过了结算期的收入可以申请提现到支付宝或微信，平台人工打款。学员退款会扣回对应收入。

## 批量生图
链接：/batch-image
「批量生图」用开启了批量生图的 Gemini 分组 Key，一次提交多条提示词（可带参考图、设置每条张数）排队出图，完成后打包下载 ZIP，按成功出图张数计费。开放情况以页面为准。

## 渠道状态、服务不可用
链接：/monitor
「渠道状态」页显示各渠道的可用情况。调用报错「Service temporarily unavailable」或「no available account」时，通常是对应分组的上游暂时不可用，可以稍后重试，或换用其他可用分组的 Key；持续出现请联系客服。

## 常见报错
链接：/usage
401 / invalid api key：Key 填错、已删除或已停用，检查 Key 或重新创建。余额不足 / quota：充值或检查 Key 的额度上限、订阅是否到期。429：请求太频繁或达到额度限制，稍后再试。模型不存在：这个分组不支持该模型，换分组或换模型。

## 隐私和安全
链接：/
网关只转发请求并记录计费所需的用量信息。网站有自建的访问统计（不用第三方统计服务）：只记录打开了哪些页面、用了哪些功能和从哪个链接进来，不记录输入的内容、提示词和 Key，IP 只保留前三段，明细 90 天后删除。不要把 API Key、密码、公众号 AppSecret 发给任何人（包括客服）；如果在聊天里或公开场合泄露了 Key，请立即在「API 密钥」页删除并重新创建。
